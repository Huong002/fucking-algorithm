# Nền tảng刷题 học online



![](https://labuladong.online/algo/images/souyisou1.png)

**Thông báo: Theo nhu cầu của đông đảo độc giả, website đã mở [lộ trình học cấp tốc](https://labuladong.online/algo/intro/quick-learning-plan/), bạn nào cần có thể xem qua, cảm ơn sự ủng hộ của mọi người~ Ngoài ra, bạn nên học bài viết trên [website](https://labuladong.online/algo/) của mình để có trải nghiệm tốt hơn.**



**-----------**

Dù tôi rảnh là thích chê giáo dục应试, nhưng tôi cũng từ应试 phát hiện một窍门: nếu có thể học kỹ năng nào đó dưới dạng刷题, hiệu suất và hiệu quả là tốt nhất. Với học技术,困境 tôi hay đối mặt là, **kiến thức lý thuyết biết không ít, nhưng có cảnh实在 không mô phỏng được, thiếu cơ hội亲自动手 thực hành**, giá mà có một cuốn bài tập có đáp án chuẩn để tôi刷 thì tốt.

Nên khi học技术 mới, tôi đầu tiên sẽ search có nền tảng刷题 online không, bạn还别 nói, có đại thần真 làm nền tảng luyện online rất不错, dưới đây giới thiệu vài nền tảng, lần lượt là nền tảng luyện online học Git, SQL, regex.

### Một, luyện Git

Đây là một project tên Learning Git Branching, là cái tôi nhất định phải推荐:

![](https://labuladong.online/algo/images/online/1.png)

Đúng như tự giới thiệu trong hội thoại, đây确实 cũng là tutorial animation Git **tốt nhất** tôi tới nay phát hiện, không có之一.

Nhớ năm đó tôi dùng Git就会 `add .`, `clone`, `push`, `pull`, `commit` mấy lệnh, lệnh khác hoàn toàn không biết, Git chính là một trình download, Github chính là web tài nguyên cộng图床 miễn phí, lệnh có达成 mục đích không đều靠运气. Cái gì version control, tôi根本搞 không hiểu, cũng lười xem đống doc乱七八糟 đó.

Tutorial của web này không cho bạn ví dụ chi tiết kiểu sửa file, mà抽象 mỗi `commit` thành node của cây, **dưới dạng闯关 animation**, để bạn tự do dùng lệnh Git hoàn thành mục tiêu:

![](https://labuladong.online/algo/images/online/2.png)

Mọi nhánh Git đều được trực quan hóa, bạn chỉ cần nhập lệnh Git ở dòng lệnh trái, nhánh sẽ biến tương ứng, chỉ cần达成 mục tiêu nhiệm vụ, bạn就 qua màn! Web còn ghi số lệnh của bạn, thử xem có thể qua với ít lệnh nhất không!

![](https://labuladong.online/algo/images/online/3.png)

Lúc đầu tôi tưởng tutorial này chỉ chứa version quản của repo Git local, **sau tôi惊奇 phát hiện nó còn có tutorial thao tác repo remote**!

![](https://labuladong.online/algo/images/online/4.png)

![](https://labuladong.online/algo/images/online/5.png)

Thật như chơi game, thiết kế độ khó hợp lý,流畅很好, tôi一玩就停 không được, mấy giờ là打通, haha!

![](https://labuladong.online/algo/images/online/6.png)

Tóm lại, tutorial này rất hợp初学 và进阶, nếu bạn thấy mình nắm Git chưa tốt, dùng lệnh Git vẫn靠碰运气, là có thể chơi tutorial này, tin là giúp bạn dùng Git熟练 hơn.

Nó là một open source project, địa chỉ Github project:

https://github.com/pcottle/learnGitBranching

Địa chỉ web tutorial:

https://learngitbranching.js.org

### Hai, luyện regex

**Regex là một công cụ非常 mạnh**, có thể nói mọi dữ liệu trong máy đều là ký tự,靠 công cụ pattern match regex này, thao tác máy có thể nói như虎添翼.

Tôi ở đây要推荐 hai web, một là nền tảng luyện, một là nền tảng test regex.

Nói nền tảng luyện trước, tên RegexOne:

![](https://labuladong.online/algo/images/online/9.png)

Trước có tutorial cơ bản, sau có vài bài regex hay gặp, ví dụ判断 email, URL, số điện thoại, hay抽取 thông tin mấu chốt log v.v.

Chỉ cần viết ra regex符合 yêu cầu, là vào được vấn đề tiếp, mấu chốt là mỗi bài còn có đáp án chuẩn, có thể click nút solution dưới xem:

![](https://labuladong.online/algo/images/online/10.png)

Địa chỉ RegexOne:

https://regexone.com/

Nói công cụ test, là một Github project tên RegExr, đây là web nó:

![](https://labuladong.online/algo/images/online/11.png)

Thấy được, nhập文本 và串 pattern regex xong, **web sẽ thêm cho regex style đẹp mà dễ nhận, tự tìm串 pattern trong文本, highlight chuỗi khớp, mà còn hiển thị chuỗi mỗi group捕获**.

Web này có thể配合 nền tảng luyện regex trước dùng, thử đủ loại biểu thức ở đây, khớp thành công xong paste qua.

Địa chỉ RegExr:

https://regexr.com/

### Ba, luyện SQL

Đây là một web tên SQLZOO, trái là mọi nội dung luyện:

![](https://labuladong.online/algo/images/online/7.png)

SQLZOO là một nền tảng luyện SQL rất好用, tiếng Anh không khó hiểu, có thể xem thẳng bản tiếng Anh, nhưng cũng có thể chuyển phồn thể Trung,比较友好.

Ở đây đều là lệnh SQL hay dùng, cho bạn một nhu cầu, bạn viết câu SQL implement kết quả query đúng. **Quan trọng nhất là, ở đây không chỉ giải thích chi tiết用法 mỗi lệnh, sau mỗi chuyên đề còn có trắc nghiệm (quiz), mà có hệ chấm, thậm chí bài khó còn có video giảng**:

![](https://labuladong.online/algo/images/online/8.png)

Còn độ khó,循序渐进, cho dù với newbie cũng rất友好, vấn đề靠 sau确实比较 có技巧性, tin đây là thứ người yêu thử thách tư duy thích! LeetCode cũng có bài SQL, nhưng độ khó一般比较大, tôi thấy SQLZOO刷 xong lệnh SQL cơ bản rồi刷 LeetCode比较 hợp.

Địa chỉ web:

https://sqlzoo.net/
