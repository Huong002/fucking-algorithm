# Nền tảng luyện đề học online



![](https://labuladong.online/algo/images/souyisou1.png)

**Thông báo: Theo nhu cầu của đông đảo độc giả, website đã mở [lộ trình học cấp tốc](https://labuladong.online/algo/intro/quick-learning-plan/), bạn nào cần có thể xem qua, cảm ơn sự ủng hộ của mọi người~ Ngoài ra, bạn nên học bài viết trên [website](https://labuladong.online/algo/) của mình để có trải nghiệm tốt hơn.**



**-----------**

Dù tôi rảnh là thích chê nền giáo dục thi cử, nhưng tôi cũng từ thi cử phát hiện một bí quyết: nếu có thể học kỹ năng nào đó dưới dạng luyện đề, hiệu suất và hiệu quả là tốt nhất. Với học kỹ thuật, khó khăn tôi hay đối mặt là, **kiến thức lý thuyết biết không ít, nhưng có tình huống thật sự không mô phỏng được, thiếu cơ hội tự tay thực hành**, giá mà có một cuốn bài tập có đáp án chuẩn để tôi luyện thì tốt.

Nên khi học kỹ thuật mới, đầu tiên tôi sẽ search xem có nền tảng luyện đề online không, bạn đừng nói chứ, có cao thủ thật sự làm ra nền tảng luyện online rất tốt, dưới đây giới thiệu vài nền tảng, lần lượt là nền tảng luyện online học Git, SQL, regex.

### Một, luyện Git

Đây là một project tên Learning Git Branching, là cái tôi nhất định phải giới thiệu:

![](https://labuladong.online/algo/images/online/1.png)

Đúng như tự giới thiệu trong hội thoại, đây đúng là tutorial animation Git **tốt nhất** tôi tới nay phát hiện, không có đối thủ.

Nhớ năm đó tôi dùng Git chỉ biết mấy lệnh `add .`, `clone`, `push`, `pull`, `commit`, lệnh khác hoàn toàn không biết, Git chính là một trình download, Github chính là web tài nguyên cộng với chỗ chứa ảnh miễn phí, lệnh có đạt được mục đích không đều nhờ may rủi. Cái gì mà version control, tôi hoàn toàn không hiểu nổi, cũng lười xem đống doc lộn xộn đó.

Tutorial của web này không cho bạn ví dụ chi tiết kiểu sửa file, mà trừu tượng hóa mỗi `commit` thành node của cây, **dưới dạng animation vượt ải**, để bạn tự do dùng lệnh Git hoàn thành mục tiêu:

![](https://labuladong.online/algo/images/online/2.png)

Mọi nhánh Git đều được trực quan hóa, bạn chỉ cần nhập lệnh Git ở dòng lệnh bên trái, nhánh sẽ biến đổi tương ứng, chỉ cần đạt được mục tiêu nhiệm vụ, bạn sẽ qua màn! Web còn ghi lại số lệnh của bạn, thử xem có thể qua với ít lệnh nhất không!

![](https://labuladong.online/algo/images/online/3.png)

Lúc đầu tôi tưởng tutorial này chỉ chứa quản lý version của repo Git local, **sau đó tôi ngạc nhiên phát hiện nó còn có cả tutorial thao tác repo remote**!

![](https://labuladong.online/algo/images/online/4.png)

![](https://labuladong.online/algo/images/online/5.png)

Thật sự như chơi game, thiết kế độ khó hợp lý, trải nghiệm rất mượt, tôi chơi một lần là không dừng được, mấy giờ là phá đảo, haha!

![](https://labuladong.online/algo/images/online/6.png)

Tóm lại, tutorial này rất hợp cho người mới học lẫn nâng cao, nếu bạn thấy mình nắm Git chưa tốt, dùng lệnh Git vẫn còn kiểu cầu may, thì có thể chơi tutorial này, tin là sẽ giúp bạn dùng Git thành thạo hơn.

Nó là một open source project, địa chỉ Github của project:

https://github.com/pcottle/learnGitBranching

Địa chỉ web tutorial:

https://learngitbranching.js.org

### Hai, luyện regex

**Regex là một công cụ vô cùng mạnh**, có thể nói mọi dữ liệu trong máy đều là ký tự, nhờ công cụ pattern match regex này, thao tác máy tính có thể nói như hổ mọc thêm cánh.

Tôi ở đây muốn giới thiệu hai web, một là nền tảng luyện tập, một là nền tảng test regex.

Nói nền tảng luyện tập trước, tên RegexOne:

![](https://labuladong.online/algo/images/online/9.png)

Trước có tutorial cơ bản, sau có vài bài regex hay gặp, ví dụ kiểm tra email, URL, số điện thoại, hay trích xuất thông tin mấu chốt trong log v.v.

Chỉ cần viết ra regex phù hợp yêu cầu, là vào được vấn đề tiếp theo, mấu chốt là mỗi bài còn có đáp án chuẩn, có thể click nút solution bên dưới để xem:

![](https://labuladong.online/algo/images/online/10.png)

Địa chỉ RegexOne:

https://regexone.com/

Nói về công cụ test, là một Github project tên RegExr, đây là web của nó:

![](https://labuladong.online/algo/images/online/11.png)

Thấy được, nhập văn bản và chuỗi pattern regex xong, **web sẽ thêm cho regex style đẹp mà dễ nhìn, tự tìm chuỗi pattern trong văn bản, highlight chuỗi khớp, mà còn hiển thị chuỗi mỗi group bắt được**.

Web này có thể phối hợp với nền tảng luyện regex kể trên để dùng, thử đủ loại biểu thức ở đây, khớp thành công xong paste qua.

Địa chỉ RegExr:

https://regexr.com/

### Ba, luyện SQL

Đây là một web tên SQLZOO, bên trái là mọi nội dung luyện tập:

![](https://labuladong.online/algo/images/online/7.png)

SQLZOO là một nền tảng luyện SQL rất dễ dùng, tiếng Anh không khó hiểu, có thể xem thẳng bản tiếng Anh, nhưng cũng có thể chuyển sang tiếng Trung phồn thể, khá thân thiện.

Ở đây đều là lệnh SQL hay dùng, cho bạn một nhu cầu, bạn viết câu SQL để cho ra kết quả query đúng. **Quan trọng nhất là, ở đây không chỉ giải thích chi tiết cách dùng mỗi lệnh, sau mỗi chuyên đề còn có trắc nghiệm (quiz), mà có hệ thống chấm điểm, thậm chí bài khó còn có video giảng**:

![](https://labuladong.online/algo/images/online/8.png)

Còn về độ khó thì tăng dần từng bước, cho dù với newbie cũng rất thân thiện, vấn đề về sau đúng là khá thử thách kỹ xảo, tin đây là thứ người yêu thử thách tư duy sẽ thích! LeetCode cũng có bài SQL, nhưng độ khó thường khá lớn, tôi thấy luyện xong lệnh SQL cơ bản ở SQLZOO rồi luyện LeetCode sẽ hợp hơn.

Địa chỉ web:

https://sqlzoo.net/
