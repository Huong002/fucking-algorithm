> [!NOTE]
> Nén không gian并不难/chủ yếu để优化 độ phức tạp không gian của vài bài quy hoạch động. Nhưng trong笔试/thi viết thường yêu cầu không gian không cao, ngay cả không dùng技巧优化 này cũng qua được, nên cá nhân mình thấy nén trạng thái không phải技巧必须掌握, bạn đọc hứng thú có thể học kỹ理解.

Tài khoản của ta trước đây viết十几/chục bài quy hoạch động, có thể nói技巧 quy hoạch động提升 hiệu quả thuật toán非常可观, nói chung đều优化 được thuật toán độ phức tạp thời gian hàm mũ và giai thừa thành O(N^2),堪称/được mệnh danh二向箔/vũ khí hai chiều của giới thuật toán,打 hết魑魅魍魉/yêu ma thành二次元/hai chiều.

Nhưng, quá trình求解 quy hoạch động cũng có thể优化 theo阶段, nếu bạn认真 quan sát phương trình chuyển trạng thái của vài bài quy hoạch động,就能降 tiếp độ phức tạp không gian của解法, từ O(N^2) xuống O(N).






> [!NOTE]
> Trước đây mình trong bài này误 dùng từ「nén trạng thái」, có bạn đọc chỉ ra含义 của「nén trạng thái」là把 nhiều trạng thái qua phép nhị phân biểu diễn bằng một số nguyên, từ đó giảm chiều mảng `dp`. Mà cách优化描述 trong bài này là qua quan sát quan hệ phụ thuộc của phương trình chuyển trạng thái, từ đó giảm chiều mảng `dp`, quả thật khác「nén trạng thái」. Nên严谨/chặt chẽ, mình sửa mọi「nén trạng thái」trong bài gốc thành「nén không gian」, tránh误用/dùng sai danh từ.

Quy hoạch động dùng được技巧 nén không gian đều là bài `dp` hai chiều, **bạn xem phương trình chuyển trạng thái của nó, nếu tính trạng thái `dp[i][j]` cần đều là trạng thái相邻/kề `dp[i][j]`, thì就可以 dùng技巧 nén không gian**, chuyển mảng `dp` hai chiều thành một chiều,降 độ phức tạp không gian từ O(N^2) xuống O(N).

Thế nào gọi「trạng thái相邻 với `dp[i][j]`」, ví dụ bài trước [Dãy con đối xứng dài nhất](https://labuladong.online/algo/dynamic-programming/subsequence-problem/)中, code cuối cùng như sau:

```java
int longestPalindromeSubseq(String s) {
    int n = s.length();
    // Mảng dp khởi tạo toàn bộ là 0
    int[][] dp = new int[n][n];
    // base case
    for (int i = 0; i < n; i++) {
        dp[i][i] = 1;
    }
    // Duyệt ngược đảm bảo chuyển trạng thái đúng
    for (int i = n - 1; i >= 0; i--) {
        for (int j = i + 1; j < n; j++) {
            // Phương trình chuyển trạng thái
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    // Độ dài chuỗi con đối xứng dài nhất của toàn bộ s
    return dp[0][n - 1];
}
```

> [!TIP]
> Bài này ta không探讨推 phương trình chuyển trạng thái thế nào, chỉ探讨技巧 nén không gian cho bài DP hai chiều.技巧 đều tổng quát, nên nếu bạn chưa xem bài trước, không hiểu logic đoạn code này cũng không sao, hoàn toàn không cản bạn học được nén không gian.

Bạn xem ta cập nhật `dp[i][j]`, thật ra chỉ phụ thuộc ba trạng thái `dp[i+1][j-1], dp[i][j-1], dp[i+1][j]`:

![](https://labuladong.online/algo/images/space-optimal/1.jpeg)

Đây gọi là相邻 với `dp[i][j]`,反正/dù sao bạn tính `dp[i][j]` chỉ cần ba trạng thái相邻 này, thật ra căn bản không cần bảng dp hai chiều lớn vậy đúng không? **思路 cốt lõi của nén không gian就是, đem mảng hai chiều「投影/chiếu」xuống mảng một chiều**:

![](https://labuladong.online/algo/images/space-optimal/2.jpeg)

Từ「投影」hẳn比较形象, nói thẳng就是 hy vọng mảng một chiều phát huy tác dụng của mảng hai chiều gốc.

思路很直观, nhưng cũng có một vấn đề rõ ràng, trong hình hai trạng thái `dp[i][j-1]` và `dp[i+1][j-1]`处 cùng một cột, mà trong mảng một chiều chỉ chứa được một, vậy chúng投影 xuống một chiều必然 một cái bị cái kia覆盖, mình còn tính `dp[i][j]` thế nào?

Đây就是难点 của nén không gian, dưới đây就来 phân tích giải quyết,还是 lấy bài「Dãy con đối xứng dài nhất」ví dụ, logic chính của phương trình chuyển trạng thái nó就是 đoạn code dưới:




```java
for (int i = n - 2; i >= 0; i--) {
    for (int j = i + 1; j < n; j++) {
        // Phương trình chuyển trạng thái
        if (s.charAt(i) == s.charAt(j)) {
            dp[i][j] = dp[i + 1][j - 1] + 2;
        } else {
            dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
        }
    }
}
```



Hồi tưởng hình trên,「投影」thật ra就是把 nhiều hàng thành một hàng, nên muốn nén mảng `dp` hai chiều thành một chiều, nói chung là bỏ chiều đầu tiên, 也就是 chiều `i`, chỉ còn chiều `j`. **Mảng `dp` một chiều sau nén chính là hàng `dp[i][..]` của mảng `dp` hai chiều trước đó**.

Ta sửa code trên trước,无脑/bỏ não bỏ chiều `i`,把 mảng `dp` thành một chiều:




```java
for (int i = n - 2; i >= 0; i--) {
    for (int j = i + 1; j < n; j++) {
        // Ở đây, số trong mảng dp một chiều là gì?
        if (s.charAt(i) == s.charAt(j)) {
            dp[j] = dp[j - 1] + 2;
        } else {
            dp[j] = Math.max(dp[j], dp[j - 1]);
        }
    }
}
```



Mảng `dp` một chiều trong code trên chỉ表示 một hàng `dp[i][..]` của mảng `dp` hai chiều. Nhưng ta muốn得到 mấy giá trị cần thiết `dp[i+1][j-1], dp[i][j-1], dp[i+1][j]` để chuyển trạng thái.

Vì vậy, ta phải nghĩ hai câu hỏi trước:

1、Trước khi gán giá trị mới cho `dp[j]`, `dp[j]`对应 với vị trí nào trong mảng `dp` hai chiều?

2、`dp[j-1]`对应 với vị trí nào trong mảng `dp` hai chiều?

**Với câu 1, trước khi gán giá trị mới cho `dp[j]`, giá trị `dp[j]` chính là giá trị tính ở lần lặp trước của vòng for ngoài, 也就是对应 vị trí `dp[i+1][j]` trong mảng `dp` hai chiều**.

**Với câu 2, giá trị `dp[j-1]` chính là giá trị tính ở lần lặp trước của vòng for trong, 也就是对应 vị trí `dp[i][j-1]` trong mảng `dp` hai chiều**.

Vậy vấn đề đã giải hơn nửa, chỉ còn trạng thái `dp[i+1][j-1]` trong mảng `dp` hai chiều ta không lấy trực tiếp từ mảng `dp` một chiều được:




```java
for (int i = n - 2; i >= 0; i--) {
    for (int j = i + 1; j < n; j++) {
        if (s.charAt(i) == s.charAt(j)) {
            // dp[i][j] = dp[i+1][j-1] + 2;
            dp[j] = ?? + 2;
        } else {
            // dp[i][j] = max(dp[i+1][j], dp[i][j-1]);
            dp[j] = Math.max(dp[j], dp[j - 1]);
        }
    }
}
```



Vì thứ tự vòng for duyệt `i` và `j` là từ trái sang phải, từ dưới lên trên, nên phát hiện, khi cập nhật mảng `dp` một chiều, `dp[i+1][j-1]` sẽ bị `dp[i][j-1]`覆盖, trong hình đánh thứ tự bốn vị trí này被遍历/được duyệt:

![](https://labuladong.online/algo/images/space-optimal/3.jpeg)

**Vậy nếu ta muốn得到 `dp[i+1][j-1]`,就必须 trước khi nó bị覆盖 dùng một biến tạm `temp`存 nó, mà giữ giá trị biến này tới lúc tính `dp[i][j]`**. Để đạt目的 này, kết hợp hình trên, ta viết code thế này:




```java
for (int i = n - 2; i >= 0; i--) {
    // Biến lưu dp[i+1][j-1]
    int pre = 0;
    for (int j = i + 1; j < n; j++) {
        int temp = dp[j];
        if (s.charAt(i) == s.charAt(j)) {
            // dp[i][j] = dp[i+1][j-1] + 2;
            dp[j] = pre + 2;
        } else {
            dp[j] = Math.max(dp[j], dp[j - 1]);
        }
        // Tới vòng tiếp theo, pre就是 dp[i+1][j-1]
        pre = temp;
    }
}
```



Đừng coi thường đoạn code này, đây là chỗ精妙/tinh diệu nhất của `dp` một chiều, biết thì không khó, không biết thì khó. Để清晰, mình dùng数值 cụ thể拆解 logic này:

Giả sử giờ `i = 5, j = 7` mà `s[5] == s[7]`, vậy giờ sẽ vào logic dưới đúng không:




```java
for (int i = 5; i--) {
    for (int j = 7; j++) {
        if (s[5] == s[7]) {
            // dp[5][7] = dp[i+1][j-1] + 2;
            dp[7] = pre + 2;
        }
    }
}
```



Mình hỏi bạn biến `pre` này là gì? Là giá trị `temp` của lần lặp trước của vòng for trong.

Vậy mình hỏi tiếp **lần lặp trước của vòng for trong** giá trị `temp` là gì? Là `dp[j-1]`也就是 `dp[6]`, nhưng chú ý, đây là `dp[6]`对应 **lần lặp trước của vòng for ngoài**, không phải `dp[6]` hiện tại.

Cái này phải对应 chỉ số mảng hai chiều理解. `dp[6]` hiện tại của bạn là `dp[i][6] = dp[5][6]` trong mảng hai chiều, mà `temp` này là `dp[i+1][6] = dp[6][6]` trong mảng hai chiều.

也就是说, biến `pre` chính là `dp[i+1][j-1] = dp[6][6]`,也就是 kết quả ta muốn.

Vậy giờ ta降维 thành công phương trình chuyển trạng thái,算 là gặm xong khúc xương cứng nhất, nhưng chú ý ta còn base case phải xử lý呀:

```java
// Mảng dp khởi tạo toàn bộ là 0
int[][] dp = new int[n][n];
// base case
for (int i = 0; i < n; i++) {
    dp[i][i] = 1;
}
```

Làm sao把 base case cũng打 thành một chiều? Rất đơn giản, nhớ nén không gian就是投影, ta把 base case投影 xuống một chiều xem:

![](https://labuladong.online/algo/images/space-optimal/4.jpeg)

base case trong mảng `dp` hai chiều全都/rơi vào mảng `dp` một chiều, không tồn tại冲突 và覆盖, nên说 ta viết code thẳng thế này là được:

```java
// base case: mảng dp một chiều khởi tạo toàn bộ là 1
int[] dp = new int[n];
Arrays.fill(dp, 1);
```

Tới đây, ta把 base case và phương trình chuyển trạng thái đều降维,实际上 đã viết ra code đầy đủ:

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        // base case: mảng dp một chiều khởi tạo toàn bộ là 1
        int[] dp = new int[n];
        Arrays.fill(dp, 1);

        for (int i = n - 2; i >= 0; i--) {
            int pre = 0;
            for (int j = i + 1; j < n; j++) {
                int temp = dp[j];
                // Phương trình chuyển trạng thái
                if (s.charAt(i) == s.charAt(j))
                    dp[j] = pre + 2;
                else
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                pre = temp;
            }
        }
        return dp[n - 1];
    }
}
```

Bài này就 kết thúc, nhưng技巧 nén không gian再牛逼, cũng dựa trên思路 quy hoạch động thông thường.

Bạn cũng thấy, dùng技巧 nén không gian降维打击 mảng `dp` hai chiều rồi, khả năng đọc của code解法变得非常差, nếu xem thẳng解法 này, ai cũng一脸懵逼/mặt đơ.优化 thuật toán就是 quá trình vậy, viết trước thuật toán đệ quy暴力 khả năng đọc很好, rồi thử运用技巧 quy hoạch động优化 bài toán con trùng lặp, cuối cùng thử dùng技巧 nén không gian优化 độ phức tạp không gian.

也就是说, bạn起码/tối thiểu熟练运用套路 trong bài trước [Giải thích套路 khung quy hoạch động](https://labuladong.online/algo/essential-technique/dynamic-programming-framework/) tìm phương trình chuyển trạng thái, viết một解法 quy hoạch động đúng, rồi mới có thể quan sát tình hình chuyển trạng thái, phân tích có thể dùng技巧 nén không gian优化 không.

Hy vọng bạn đọc稳扎稳打/vững chắc,层层递进/từng lớp, với优化极限 thế này, không làm cũng罢/thôi. Dù sao套路存于心/hiểu trong lòng, đi khắp thiên hạ都不怕!
