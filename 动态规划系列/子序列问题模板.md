Bài toán dãy con là bài toán thuật toán thường gặp, mà并不好/không dễ giải.

Trước hết, bài toán dãy con本身/vốn đã相对 khó hơn chuỗi con (substring), mảng con (subarray), vì前者 là dãy không liên tục, mà hai cái sau liên tục, ngay cả liệt kê你都不一定/bạn chưa chắc đã liệt kê được,更别说/đừng nói求 giải bài toán thuật toán liên quan.

Mà, bài toán dãy con rất có thể liên quan tới hai chuỗi, ví dụ bài trước [Dãy con chung dài nhất](https://labuladong.online/algo/dynamic-programming/longest-common-subsequence/), nếu không có kinh nghiệm xử lý nhất định, thật không dễ nghĩ ra. Nên bài này就来扒一扒/mổ xẻ套路 bài toán dãy con, thật ra就 có hai template, bài liên quan cứ往/hướng hai思路 này mà nghĩ,十拿九稳/chắc ăn.

Nói chung, dạng bài này đều bắt bạn求 một **dãy con dài nhất**, vì dãy con ngắn nhất就是 một ký tự嘛,没啥/không có gì可問/đáng hỏi. Một khi liên quan dãy con và最值/giá trị cực trị, thì几乎肯定/chắc chắn **khảo技巧 quy hoạch động, độ phức tạp thời gian thường là O(n^2)**.

Nguyên nhân rất đơn giản, bạn nghĩ xem một chuỗi, dãy con của nó có bao nhiêu khả năng?起码/ít nhất là hàm mũ吧, trong trường hợp này, không dùng技巧 quy hoạch động, còn想咋样/muốn sao nữa?

既然 Đã dùng quy hoạch động, thì phải định nghĩa mảng `dp`, tìm quan hệ chuyển trạng thái. Hai思路 template ta nói, chính là思路 định nghĩa mảng `dp`. Bài khác nhau có thể cần định nghĩa mảng `dp` khác nhau để giải.

## Một, hai思路






**1、思路 template thứ nhất là mảng `dp` một chiều**:

```java
int n = array.length;
int[] dp = new int[n];

for (int i = 1; i < n; i++) {
    for (int j = 0; j < i; j++) {
        dp[i] = 最值/giá trị cực trị(dp[i], dp[j] + ...)
    }
}
```

Ví dụ [Dãy con tăng dài nhất](https://labuladong.online/algo/dynamic-programming/longest-increasing-subsequence/) và [Tổng mảng con lớn nhất](https://labuladong.online/algo/dynamic-programming/maximum-subarray/) ta đã viết đều là思路 này.

Trong思路 này định nghĩa mảng `dp` là:

**Trong mảng con `arr[0..i]`, độ dài dãy con kết thúc bằng `arr[i]` là `dp[i]`**.

Vì sao dãy con tăng dài nhất cần思路 này? Bài trước nói很清楚/rất rõ, vì như vậy符合/phù hợp quy nạp, tìm được quan hệ chuyển trạng thái, ở đây không展开 cụ thể nữa.

**2、思路 template thứ hai là mảng `dp` hai chiều**:

```java
int n = arr.length;
int[][] dp = new dp[n][n];

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        if (arr[i] == arr[j]) 
            dp[i][j] = dp[i][j] + ...
        else
            dp[i][j] = 最值(...)
    }
}
```

思路 này运用相对/relatively dùng nhiều hơn, nhất là khi liên quan dãy con của hai chuỗi/mảng, ví dụ bài trước讲 [Dãy con chung dài nhất](https://labuladong.online/algo/dynamic-programming/longest-common-subsequence/) và [Khoảng cách chỉnh sửa](https://labuladong.online/algo/dynamic-programming/edit-distance/);思路 này cũng dùng được cho情景/chỉ một chuỗi/mảng, ví dụ bài toán dãy con đối xứng讲 trong bài này.

**2.1情景 liên quan hai chuỗi/mảng**, định nghĩa mảng `dp` như sau:

**Trong mảng con `arr1[0..i]` và mảng con `arr2[0..j]`, độ dài dãy con ta yêu cầu là `dp[i][j]`**.

**2.2 Chỉ liên quan một chuỗi/mảng**, định nghĩa mảng `dp` như sau:

**Trong mảng con `array[i..j]`, độ dài dãy con ta yêu cầu là `dp[i][j]`**.

Dưới đây就 xem bài toán dãy con đối xứng dài nhất, giải chi tiết trường hợp thứ hai dùng quy hoạch động thế nào.

## Hai, dãy con đối xứng dài nhất

Trước đây giải bài [Chuỗi con đối xứng dài nhất](https://labuladong.online/algo/essential-technique/array-two-pointers-summary/), lần này nâng độ khó, xem bài 516「Dãy con đối xứng dài nhất」trên LeetCode,求 độ dài dãy con đối xứng dài nhất:

Nhập một chuỗi `s`, hãy tìm độ dài dãy con đối xứng dài nhất trong `s`, chữ ký hàm như sau:

```java
int longestPalindromeSubseq(String s);
```

Ví dụ nhập `s = "aecda"`, thuật toán trả về 3, vì dãy con đối xứng dài nhất là `"aca"`, độ dài là 3.

Ta định nghĩa mảng `dp` là: **trong chuỗi con `s[i..j]`, độ dài dãy con đối xứng dài nhất là `dp[i][j]`**. Nhất định phải nhớ định nghĩa này mới理解 được thuật toán.

Vì sao bài này phải định nghĩa mảng `dp` hai chiều vậy? Trong [Dãy con tăng dài nhất](https://labuladong.online/algo/dynamic-programming/longest-increasing-subsequence/) mình提到, tìm chuyển trạng thái cần tư duy quy nạp,说白了/nói thẳng就是 làm sao từ kết quả đã biết推出 phần chưa biết. Mà định nghĩa như vậy進行/quy nạp được, dễ phát hiện quan hệ chuyển trạng thái.

Cụ thể, nếu ta muốn求 `dp[i][j]`, giả sử bạn đã biết kết quả bài toán con `dp[i+1][j-1]` (độ dài dãy con đối xứng dài nhất trong `s[i+1..j-1]`), bạn có想办法/nghĩ cách算 ra giá trị `dp[i][j]` (trong `s[i..j]`, độ dài dãy con đối xứng dài nhất) không?

![](https://labuladong.online/algo/images/lps/1.jpg)

Được! Điều này取决/phụ thuộc ký tự `s[i]` và `s[j]`:

**Nếu chúng bằng nhau**, thì chúng cộng với dãy con đối xứng dài nhất trong `s[i+1..j-1]` chính là dãy con đối xứng dài nhất của `s[i..j]`:

![](https://labuladong.online/algo/images/lps/2.jpg)

**Nếu chúng không bằng nhau**,说明 chúng **không thể đồng thời** xuất hiện trong dãy con đối xứng dài nhất của `s[i..j]`, vậy đem chúng **分别/lần lượt**加入/thêm vào `s[i+1..j-1]`, xem chuỗi con nào sinh dãy con đối xứng dài hơn là được:

![](https://labuladong.online/algo/images/lps/3.jpg)

Hai trường hợp trên viết thành code就是 vậy:




```java
if (s[i] == s[j])
    // Chúng nhất định nằm trong dãy con đối xứng dài nhất
    dp[i][j] = dp[i + 1][j - 1] + 2;
else
    // s[i+1..j] và s[i..j-1] dãy con đối xứng của ai dài hơn?
    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
```



Tới đây, phương trình chuyển trạng thái就 viết ra, theo định nghĩa mảng dp, thứ ta yêu cầu就是 `dp[0][n - 1]`,也就是 độ dài dãy con đối xứng dài nhất của toàn bộ `s`.

## Ba, hiện thực code

Trước hết明确 base case, nếu chỉ có một ký tự, hiển nhiên độ dài dãy con đối xứng dài nhất là 1,也就是 `dp[i][j] = 1 (i == j)`.

Vì `i`肯定/chắc chắn nhỏ hơn hoặc bằng `j`, nên với những vị trí `i > j`, căn bản không tồn tại dãy con gì, nên khởi tạo là 0.

Ngoài ra, xem phương trình chuyển trạng thái vừa viết, muốn求 `dp[i][j]` cần biết ba vị trí `dp[i+1][j-1]`, `dp[i+1][j]`, `dp[i][j-1]`; lại xem base case ta xác định, sau khi điền vào mảng `dp` là thế này:

![](https://labuladong.online/algo/images/lps/4.jpg)

**Để đảm bảo mỗi lần tính `dp[i][j]`, vị trí hướng左下/trái-dưới-phải đã tính xong, chỉ斜着/chéo hoặc ngược mà duyệt**:

![](https://labuladong.online/algo/images/lps/5.jpg)

> [!TIP]
> Về hướng duyệt mảng `dp`, chi tiết xem [Giải đáp quy hoạch động](https://labuladong.online/algo/dynamic-programming/faq-summary/).

Mình chọn duyệt ngược, code như sau:

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        // Mảng dp khởi tạo toàn bộ là 0
        int[][] dp = new int[n][n];
        // base case
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;
        }
        // Duyệt ngược đảm bảo chuyển trạng thái đúng
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                // Phương trình chuyển trạng thái
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        // Độ dài chuỗi con đối xứng dài nhất của toàn bộ s
        return dp[0][n - 1];
    }
}
```

## Bốn,拓展/mở rộng

Tuy bài liên quan回文/đối xứng không có情景 dùng特别 rộng, nhưng bạn tính được dãy con đối xứng dài nhất rồi, vài bài tương tự cũng tiện tay làm luôn.

Ví dụ bài 1312「Tính số lần chèn ít nhất để chuỗi thành回文」trên LeetCode:

Nhập một chuỗi `s`, bạn có thể chèn ký tự bất kỳ tại vị trí bất kỳ trong chuỗi. Nếu muốn biến `s` thành回文, hãy tính ít nhất phải chèn mấy lần?

Chữ ký hàm như sau:

```java
int minInsertions(String s);
```

Ví dụ nhập `s = "abcea"`, thuật toán trả về 2, vì có thể chèn 2 ký tự vào `s` thành回文 `"abeceba"` hoặc `"aebcbea"`. Nếu nhập `s = "aba"`, thuật toán trả về 0, vì `s` đã là回文, không cần chèn ký tự nào.

Đây cũng là bài toán dãy con đơn chuỗi, nên ta cũng dùng mảng `dp` hai chiều, trong đó định nghĩa `dp[i][j]` như sau:

**Với chuỗi `s[i..j]`, ít nhất cần `dp[i][j]` lần chèn mới thành回文**.

Theo định nghĩa mảng `dp`, base case就是 `dp[i][i] = 0`, vì ký tự đơn本身/vốn đã là回文, không cần chèn.

Rồi dùng quy nạp toán học, giả sử đã tính giá trị bài toán con `dp[i+1][j-1]`, nghĩ cách推出 giá trị `dp[i][j]`:

![](https://labuladong.online/algo/images/palindrome-insert/1.jpeg)

Thật ra非常 tương tự phương trình chuyển trạng thái của bài dãy con đối xứng dài nhất, ở đây cũng chia hai trường hợp:




```java
if (s[i] == s[j]) {
    // Không cần chèn ký tự nào
    dp[i][j] = dp[i + 1][j - 1];
} else {
    // Biến s[i+1..j] và s[i..j-1] thành回文, chọn bên chèn ít hơn
    // rồi còn phải chèn thêm một s[i] hoặc s[j], để s[i..j]配 thành回文
    dp[i][j] = min(dp[i + 1][j], dp[i][j - 1]) + 1;
}
```



Cuối cùng, ta依然/vẫn duyệt ngược mảng `dp`, viết code:

```java
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        // dp[i][j]表示 số lần chèn ít nhất để biến chuỗi s[i..j] thành回文
        // Mảng dp khởi tạo toàn bộ là 0
        int[][] dp = new int[n][n];
        // Duyệt ngược đảm bảo chuyển trạng thái đúng
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i + 1; j < n; j++) {
                // Phương trình chuyển trạng thái
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1];
                } else {
                    dp[i][j] = Math.min(dp[i + 1][j], dp[i][j - 1]) + 1;
                }
            }
        }
        // Số lần chèn ít nhất của toàn bộ s
        return dp[0][n - 1];
    }
}
```

Tới đây, bài này cũng dùng template giải bài dãy con giải xong, logic tổng thể非常 tương tự dãy con đối xứng dài nhất, vậy bài này có thể复用 trực tiếp解法 dãy con đối xứng không?

Thật ra được, ta甚至 còn không cần viết phương trình chuyển trạng thái, bạn nghĩ kỹ xem:

**Mình tính trước dãy con đối xứng dài nhất trong chuỗi `s`, những ký tự không nằm trong dãy con đối xứng dài nhất, chẳng phải chính là ký tự cần chèn sao**?

Nên bài này复用 trực tiếp hàm `longestPalindromeSubseq` hiện thực trước đó:

```java
class Solution {
    // Tính số lần chèn ít nhất để biến s thành回文
    public int minInsertions(String s) {
        return s.length() - longestPalindromeSubseq(s);
    }

    // Tính độ dài dãy con đối xứng dài nhất trong s
    int longestPalindromeSubseq(String s) {
        // Xem phần trên
    }
}
```
