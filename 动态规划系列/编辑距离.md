## Một,思路

Bài toán khoảng cách chỉnh sửa就是 cho ta hai chuỗi `s1` và `s2`, chỉ dùng ba thao tác, bắt ta biến `s1` thành `s2`,求 số thao tác ít nhất. Cần明确 là, dù biến `s1` thành `s2` hay ngược lại, kết quả đều như nhau, nên phần sau以/lấy `s1` biến thành `s2` ví dụ.

> [!TIP]
> Giải bài toán quy hoạch động hai chuỗi, thường đều dùng hai con trỏ `i, j`分别 trỏ đầu hoặc尾/cuối hai chuỗi, rồi thử viết phương trình chuyển trạng thái.
>
> Ví như cho `i, j`分别 trỏ尾 hai chuỗi, định nghĩa `dp[i], dp[j]` là khoảng cách chỉnh sửa của chuỗi con `s1[0..i], s2[0..j]`, thì quá trình `i, j` từng bước tiến lên trước, chính là quá trình规模 bài toán (độ dài chuỗi con)逐步/giảm dần.
>
> Đương nhiên, bạn muốn cho `i, j`分别 trỏ đầu chuỗi, rồi từng bước tiến về sau cũng được,本质/bản chất并无区别/không khác, chỉ cần sửa định nghĩa hàm/mảng `dp` là được.

Đặt hai chuỗi分别是 `"rad"` và `"apple"`, cho hai con trỏ `i, j`分别 trỏ尾 hai chuỗi `s1, s2`, để biến `s1` thành `s2`, thuật toán sẽ tiến hành thế này:

## Hai, giải chi tiết code

梳理/lược lại思路 trước đó:

base case là `i` đi hết `s1` hoặc `j` đi hết `s2`, trả về trực tiếp độ dài còn lại của chuỗi kia.

Với mỗi cặp ký tự `s1[i]` và `s2[j]`, có thể có bốn thao tác:

```python
if s1[i] == s2[j]:
   啥都别/đừng làm gì (skip)
    i, j đồng thời tiến lên trước
else:
    Ba chọn một:
        chèn (insert)
        xóa (delete)
        thay thế (replace)
```

Có khung này, bài toán就 đã giải xong. Bạn đọc có thể hỏi,「ba chọn một」này rốt cuộc chọn thế nào? Rất đơn giản, thử hết một lượt, thao tác nào cuối cùng được khoảng cách chỉnh sửa nhỏ nhất, thì chọn nó. Ở đây cần技巧 đệ quy, xem code解法暴力 trước:

```java
class Solution {
    public int minDistance(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        // i, j khởi tạo trỏ chỉ số cuối cùng
        return dp(s1, m - 1, s2, n - 1);
    }

    // Định nghĩa: trả về khoảng cách chỉnh sửa nhỏ nhất của s1[0..i] và s2[0..j]
    int dp(String s1, int i, String s2, int j) {
        // base case
        if (i == -1) return j + 1;
        if (j == -1) return i + 1;

        if (s1.charAt(i) == s2.charAt(j)) {
            // Không làm gì
            return dp(s1, i - 1, s2, j - 1);
        }
        return min(
            // Chèn
            dp(s1, i, s2, j - 1) + 1,
            // Xóa
            dp(s1, i - 1, s2, j) + 1,
            // Thay thế
            dp(s1, i - 1, s2, j - 1) + 1
        );
    }

    int min(int a, int b, int c) {
        return Math.min(a, Math.min(b, c));
    }
}
```

Dưới đây giải thích chi tiết đoạn code đệ quy này, base case hẳn không cần giải thích, chủ yếu giải thích phần đệ quy.

Đều nói tính可解释/giải thích của code đệ quy很好, điều này có lý, chỉ cần理解 định nghĩa hàm,就能理解 rõ logic thuật toán. Định nghĩa hàm `dp` ở đây là:

```java

```

Giờ, bạn hẳn理解 hoàn toàn đoạn code短小精悍/ngắn gọn này. Còn vấn đề nhỏ就是,解法 này là解法暴力, tồn tại bài toán con trùng lặp, cần dùng技巧 quy hoạch động优化.

**Làm sao nhìn một cái ra tồn tại bài toán con trùng lặp**? Trong [Giải đáp quy hoạch động](https://labuladong.online/algo/dynamic-programming/faq-summary/) mình có讲, ở đây nhắc đơn giản, cần抽象/trừu tượng hóa khung đệ quy của thuật toán trong bài:

```java
int dp(i, j) {
    dp(i - 1, j - 1); // #1
    dp(i, j - 1);     // #2
    dp(i - 1, j);     // #3
}
```

Với bài toán con `dp(i-1, j-1)`, qua bài gốc `dp(i, j)`得到 thế nào? Có không chỉ một đường, ví dụ `dp(i, j) -> #1` và `dp(i, j) -> #2 -> #3`. Một khi phát hiện một đường lặp,則说明 tồn tại巨量/vô số đường lặp, 也就是 bài toán con trùng lặp.

## Ba,优化 quy hoạch động

Với bài toán con trùng lặp, bài trước [Giải thích chi tiết quy hoạch động](https://labuladong.online/algo/essential-technique/dynamic-programming-framework/) giới thiệu chi tiết, phương pháp优化 chẳng qua là thêm bảng ghi nhớ cho解法 đệ quy, hoặc把/quá trình DP dùng bảng DP lặp hiện thực, dưới đây逐个讲.

###解法 bảng ghi nhớ

既然解法 đệ quy暴力都 viết ra, bảng ghi nhớ rất dễ thêm, code gốc sửa nhẹ là được:

```java
class Solution {
    // Bảng ghi nhớ
    int[][] memo;
        
    public int minDistance(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        // Bảng ghi nhớ khởi tạo giá trị đặc biệt,代表 chưa tính
        memo = new int[m][n];
        for (int[] row : memo) {
            Arrays.fill(row, -1);
        }
        return dp(s1, m - 1, s2, n - 1);
    }

    int dp(String s1, int i, String s2, int j) {
        if (i == -1) return j + 1;
        if (j == -1) return i + 1;
        // Tra bảng ghi nhớ, tránh bài toán con trùng lặp
        if (memo[i][j] != -1) {
            return memo[i][j];
        }
        // Chuyển trạng thái, kết quả lưu vào bảng ghi nhớ
        if (s1.charAt(i) == s2.charAt(j)) {
            memo[i][j] = dp(s1, i - 1, s2, j - 1);
        } else {
            memo[i][j] =  min(
                dp(s1, i, s2, j - 1) + 1,
                dp(s1, i - 1, s2, j) + 1,
                dp(s1, i - 1, s2, j - 1) + 1
            );
        }
        return memo[i][j];
    }

    int min(int a, int b, int c) {
        return Math.min(a, Math.min(b, c));
    }
}
```

###解法 bảng DP

Chủ yếu nói解法 bảng DP, ta cần định nghĩa một mảng `dp`, rồi trên mảng này thực hiện phương trình chuyển trạng thái.

Trước hết明确含义 mảng `dp`, vì bài này có hai trạng thái (chỉ số `i` và `j`), nên mảng `dp` là mảng hai chiều,大致 dài thế này:

![](https://labuladong.online/algo/images/editDistance/dp.jpg)

Chuyển trạng thái giống解法 đệ quy, `dp[..][0]` và `dp[0][..]`对应 base case,含义 `dp[i][j]` tương tự định nghĩa hàm `dp` trước đó:




```java
int dp(String s1, int i, String s2, int j)
// Trả về khoảng cách chỉnh sửa nhỏ nhất của s1[0..i] và s2[0..j]

dp[i-1][j-1]
// Lưu khoảng cách chỉnh sửa nhỏ nhất của s1[0..i] và s2[0..j]
```



base case của hàm `dp` là `i, j` bằng -1, mà chỉ số mảng ít nhất là 0, nên mảng `dp` sẽ lệch một vị.

既然含义 mảng `dp` và hàm `dp` đệ quy như nhau, cũng就可以套 thẳng思路 trước đó viết code, **khác duy nhất là,解法 đệ quy là求解 top-down (bắt đầu từ bài gốc,逐步 phân rã tới base case), bảng DP là求解 bottom-up (bắt đầu từ base case,推演 về bài gốc)**:

```java
class Solution {
    public int minDistance(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        // Định nghĩa: khoảng cách chỉnh sửa nhỏ nhất của s1[0..i] và s2[0..j] là dp[i+1][j+1]
        int[][] dp = new int[m + 1][n + 1];
        // base case 
        for (int i = 1; i <= m; i++)
            dp[i][0] = i;
        for (int j = 1; j <= n; j++)
            dp[0][j] = j;
        //求解 bottom-up
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s1.charAt(i-1) == s2.charAt(j-1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = min(
                        dp[i - 1][j] + 1,
                        dp[i][j - 1] + 1,
                        dp[i - 1][j - 1] + 1
                    );
                }
            }
        }
        // Lưu khoảng cách chỉnh sửa nhỏ nhất của toàn bộ s1 và s2
        return dp[m][n];
    }

    int min(int a, int b, int c) {
        return Math.min(a, Math.min(b, c));
    }
}
```

## Bốn,扩展/mở rộng

Nói chung, xử lý bài toán quy hoạch động hai chuỗi, đều xử lý theo思路 trong bài, lập bảng DP. Vì sao? vì dễ tìm quan hệ chuyển trạng thái, ví dụ bảng DP của khoảng cách chỉnh sửa:

![](https://labuladong.online/algo/images/editDistance/4.jpg)

Còn một chi tiết,既然 mỗi `dp[i][j]` chỉ liên quan ba trạng thái gần nó, độ phức tạp không gian có thể nén thành $O(min(M, N))$ (M, N là độ dài hai chuỗi). Không khó, nhưng tính可解释 giảm mạnh, bạn đọc tự thử优化.

Bạn còn có thể hỏi, **ở đây chỉ求 ra khoảng cách chỉnh sửa nhỏ nhất, vậy thao tác cụ thể là gì**? Ví dụ sửa bài公众号 vừa nêu, chỉ có khoảng cách chỉnh sửa nhỏ nhất肯定 không đủ, còn phải biết sửa cụ thể thế nào.

Thật ra rất đơn giản, code sửa nhẹ, cho mảng dp thêm thông tin là được:

```java
// int[][] dp;
Node[][] dp;

class Node {
    int val;
    int choice;
    // 0代表 không làm gì
    // 1代表 chèn
    // 2代表 xóa
    // 3代表 thay thế
}
```

Thuộc tính `val` chính là数值 của mảng dp trước đó, thuộc tính `choice`代表 thao tác. Khi lựa chọn tối ưu, tiện tay ghi thao tác lại, rồi就 từ kết quả反推 thao tác cụ thể.

Kết quả cuối của ta chẳng phải `dp[m][n]` sao, `val` ở đây存 khoảng cách chỉnh sửa nhỏ nhất, `choice`存 thao tác cuối cùng, ví dụ là thao tác chèn, thì就可以左移/dời trái một ô:

![](https://labuladong.online/algo/images/editDistance/5.jpg)

Lặp quá trình này, có thể từng bước quay về起点 `dp[0][0]`,形成 một đường,按 thao tác trên đường này编辑, chính là phương án tốt nhất.

![](https://labuladong.online/algo/images/editDistance/6.jpg)

Theo yêu cầu mọi người, mình viết思路 này ra, bạn tự chạy thử:

```java
int minDistance(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    Node[][] dp = new Node[m + 1][n + 1];
    // base case
    for (int i = 0; i <= m; i++) {
        // s1 chuyển thành s2 chỉ cần xóa một ký tự
        dp[i][0] = new Node(i, 2);
    }
    for (int j = 1; j <= n; j++) {
        // s1 chuyển thành s2 chỉ cần chèn một ký tự
        dp[0][j] = new Node(j, 1);
    }
    // Phương trình chuyển trạng thái
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i-1) == s2.charAt(j-1)){
                // Nếu hai ký tự giống nhau, thì không cần làm gì
                Node node = dp[i - 1][j - 1];
                dp[i][j] = new Node(node.val, 0);
            } else {
                // Ngược lại, ghi thao tác代价/giá nhỏ nhất
                dp[i][j] = minNode(
                    dp[i - 1][j],
                    dp[i][j - 1],
                    dp[i-1][j-1]
                );
                // Và cộng khoảng cách chỉnh sửa lên một
                dp[i][j].val++;
            }
        }
    }
    // Theo bảng dp反推 quá trình thao tác cụ thể và in
    printResult(dp, s1, s2);
    return dp[m][n].val;
}

// Tính thao tác代价 nhỏ nhất trong delete, insert, replace
Node minNode(Node a, Node b, Node c) {
    Node res = new Node(a.val, 2);
    
    if (res.val > b.val) {
        res.val = b.val;
        res.choice = 1;
    }
    if (res.val > c.val) {
        res.val = c.val;
        res.choice = 3;
    }
    return res;
}
```

Cuối cùng, hàm `printResult`反推 kết quả và in thao tác cụ thể:

```java
void printResult(Node[][] dp, String s1, String s2) {
    int rows = dp.length;
    int cols = dp[0].length;
    int i = rows - 1, j = cols - 1;
    System.out.println("Change s1=" + s1 + " to s2=" + s2 + ":\n");
    while (i != 0 && j != 0) {
        char c1 = s1.charAt(i - 1);
        char c2 = s2.charAt(j - 1);
        int choice = dp[i][j].choice;
        System.out.print("s1[" + (i - 1) + "]:");
        switch (choice) {
            case 0:
                // Bỏ qua, thì hai con trỏ đồng thời tiến
                System.out.println("skip '" + c1 + "'");
                i--; j--;
                break;
            case 1:
                // Chèn s2[j] vào s1[i], thì con trỏ s2 tiến
                System.out.println("insert '" + c2 + "'");
                j--;
                break;
            case 2:
                // Xóa s1[i], thì con trỏ s1 tiến
                System.out.println("delete '" + c1 + "'");
                i--;
                break;
            case 3:
                // Thay s1[i] thành s2[j], thì hai con trỏ đồng thời tiến
                System.out.println(
                    "replace '" + c1 + "'" + " with '" + c2 + "'");
                i--; j--;
                break;
        }
    }
    // Nếu s1 còn chưa đi hết, thì phần còn lại đều cần xóa
    while (i > 0) {
        System.out.print("s1[" + (i - 1) + "]:");
        System.out.println("delete '" + s1.charAt(i - 1) + "'");
        i--;
    }
    // Nếu s2 còn chưa đi hết, thì phần còn lại đều cần chèn vào s1
    while (j > 0) {
        System.out.print("s1[0]:");
        System.out.println("insert '" + s2.charAt(j - 1) + "'");
        j--;
    }
}
```
