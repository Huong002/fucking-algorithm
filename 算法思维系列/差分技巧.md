[Kỹ thuật tổng tiền tố](https://labuladong.online/algo/data-structure/prefix-sum/) cảnh适用 chủ yếu là trong trường hợp mảng gốc không bị sửa, truy vấn thường xuyên tổng dồn của một đoạn nào đó, code cốt lõi chính là đoạn sau:

```java
class PrefixSum {
    // Mảng tổng tiền tố
    private int[] preSum;

    // Nhập một mảng, dựng tổng tiền tố
    public PrefixSum(int[] nums) {
        // preSum[0] = 0, tiện cho việc tính tổng dồn
        preSum = new int[nums.length + 1];
        // Tính tổng dồn của nums
        for (int i = 1; i < preSum.length; i++) {
            preSum[i] = preSum[i - 1] + nums[i - 1];
        }
    }

    // Truy vấn tổng dồn của đoạn đóng [left, right]
    public int sumRange(int left, int right) {
        return preSum[right + 1] - preSum[left];
    }
}
```

![](https://labuladong.online/algo/images/difference/1.jpeg)

`preSum[i]`就 đại diện tổng dồn tất cả phần tử của `nums[0..i-1]`, nếu chúng ta muốn求 tổng dồn của đoạn `nums[i..j]`, chỉ cần tính `preSum[j+1] - preSum[i]` là được, mà không cần duyệt toàn bộ đoạn để求 tổng.

Bài này讲 một技巧 thuật toán rất tương tự tư tưởng tổng tiền tố là 「mảng hiệu」, **cảnh适用 chủ yếu của mảng hiệu là thường xuyên tăng/giảm phần tử trên một đoạn nào đó của mảng gốc**.

Ví dụ, tôi cho bạn nhập một mảng `nums`, rồi lại yêu cầu cho đoạn `nums[2..6]` toàn bộ cộng 1, rồi cho `nums[3..9]` toàn bộ trừ 3, rồi cho `nums[0..4]` toàn bộ cộng 2, rồi...

Một通 thao tác猛 như hổ, rồi hỏi bạn, cuối cùng giá trị mảng `nums` là gì?

思路 thông thường rất dễ, bạn bắt tôi cho đoạn `nums[i..j]` cộng `val`, vậy tôi một vòng for cộng hết cho chúng呗, còn能咋样? Độ phức tạp thời gian của思路 này là $O(N)$, do trong cảnh này sửa `nums` rất thường xuyên, nên hiệu suất sẽ rất thấp.

Chỗ này cần技巧 mảng hiệu, tương tự mảng `preSum` mà kỹ thuật tổng tiền tố dựng, chúng ta先 dựng một mảng hiệu `diff` cho mảng `nums`, **`diff[i]` chính là hiệu của `nums[i]` và `nums[i-1]`**:

```java
int[] diff = new int[nums.length];
// Dựng mảng hiệu
diff[0] = nums[0];
for (int i = 1; i < nums.length; i++) {
    diff[i] = nums[i] - nums[i - 1];
}
```

![](https://labuladong.online/algo/images/difference/2.jpeg)

Thông qua mảng hiệu `diff` này có thể suy ngược ra mảng gốc `nums`, logic code như sau:

```java
int[] res = new int[diff.length];
// Suy ra mảng kết quả theo mảng hiệu
res[0] = diff[0];
for (int i = 1; i < diff.length; i++) {
    res[i] = res[i - 1] + diff[i];
}
```

**Dựng mảng hiệu `diff` như vậy, là có thể tiến hành thao tác tăng giảm theo đoạn nhanh chóng**, nếu bạn muốn cho phần tử của đoạn `nums[i..j]` toàn bộ cộng 3, vậy chỉ cần让 `diff[i] += 3`, rồi让 `diff[j+1] -= 3` là được:

![](https://labuladong.online/algo/images/difference/3.jpeg)

**Nguyên lý rất đơn giản, nhớ lại quá trình mảng `diff` suy ngược mảng `nums`, `diff[i] += 3` nghĩa là cho tất cả phần tử của `nums[i..]` đều cộng 3, rồi `diff[j+1] -= 3` lại nghĩa là với tất cả phần tử của `nums[j+1..]` lại trừ 3, vậy tổng hợp lại, có phải chính là cho tất cả phần tử trong `nums[i..j]` đều cộng 3 không**?

Chỉ cần tốn thời gian O(1) sửa mảng `diff`,就相当于 cho toàn bộ đoạn của `nums` làm sửa đổi. Sửa `diff` nhiều lần, rồi thông qua mảng `diff` suy ngược, là có thể得到 kết quả sau khi `nums` sửa đổi.

Bây giờ chúng ta trừu tượng hóa mảng hiệu thành một lớp, bao gồm phương thức `increment` và phương thức `result`:

```java
// Lớp công cụ mảng hiệu
class Difference {
    // Mảng hiệu
    private int[] diff;

    // Nhập một mảng ban đầu, thao tác theo đoạn sẽ tiến hành trên mảng này
    public Difference(int[] nums) {
        assert nums.length > 0;
        diff = new int[nums.length];
        // Dựng mảng hiệu theo mảng ban đầu
        diff[0] = nums[0];
        for (int i = 1; i < nums.length; i++) {
            diff[i] = nums[i] - nums[i - 1];
        }
    }

    // Cho đoạn đóng [i, j] tăng val (có thể là số âm)
    public void increment(int i, int j, int val) {
        diff[i] += val;
        if (j + 1 < diff.length) {
            diff[j + 1] -= val;
        }
    }

    // Trả về mảng kết quả
    public int[] result() {
        int[] res = new int[diff.length];
        // Suy ra mảng kết quả theo mảng hiệu
        res[0] = diff[0];
        for (int i = 1; i < diff.length; i++) {
            res[i] = res[i - 1] + diff[i];
        }
        return res;
    }
}
```

Chỗ này chú ý câu if trong phương thức `increment`:

```java
void increment(int i, int j, int val) {
    diff[i] += val;
    if (j + 1 < diff.length) {
        diff[j + 1] -= val;
    }
}
```

Khi `j+1 >= diff.length`时, nghĩa là cho `nums[i]` và toàn bộ mảng về sau đều tiến hành sửa đổi, vậy就不需要 cho mảng `diff` trừ `val` nữa.

## Thực hành thuật toán

Trước hết, LeetCode 370 「Cộng theo đoạn」就 trực tiếp khảo sát技巧 mảng hiệu:

<Problem slug="range-addition" />

Vậy chúng ta trực tiếp复用 lớp `Difference` vừa cài đặt là có thể giải bài này:

```java
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        // nums khởi tạo toàn 0
        int[] nums = new int[length];
        // Dựng giải pháp hiệu
        Difference df = new Difference(nums);

        for (int[] update : updates) {
            int i = update[0];
            int j = update[1];
            int val = update[2];
            df.increment(i, j, val);
        }

        return df.result();
    }
}
```

Đương nhiên, đề thuật toán thực tế có thể cần chúng ta liên tưởng và trừu tượng hóa đề bài, sẽ không trực tiếp để bạn nhìn ra要用技巧 mảng hiệu như vậy, chỗ này xem LeetCode 1109 「Thống kê đặt vé máy bay」:

<Problem slug="corporate-flight-bookings" />

Chữ ký hàm như sau:

```java
int[] corpFlightBookings(int[][] bookings, int n)
```

Đề này就在绕弯弯, thực ra nó chính là một bài mảng hiệu, tôi dịch cho bạn:

Cho bạn nhập một mảng `nums` độ dài `n`, trong đó tất cả phần tử đều là 0. Lại cho bạn nhập một `bookings`, bên trong là若干 bộ ba `(i, j, k)`, mỗi bộ ba nghĩa là yêu cầu bạn cho tất cả phần tử trong đoạn đóng `[i-1,j-1]` của mảng `nums` đều cộng `k`. Hãy trả về mảng `nums` cuối cùng là gì?

> [!NOTE]
> Vì `n` mà đề nói đếm từ 1, mà chỉ số mảng đếm từ 0, nên với bộ ba nhập `(i, j, k)`, đoạn mảng hẳn tương ứng `[i-1,j-1]`.

Nhìn như vậy, chẳng phải là một bài mảng hiệu chuẩn sao? Chúng ta có thể trực tiếp复用 lớp vừa viết:

```java
class Solution {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        // nums khởi tạo toàn 0
        int[] nums = new int[n];
        // Dựng giải pháp hiệu
        Difference df = new Difference(nums);

        for (int[] booking : bookings) {
            // Chú ý chuyển thành chỉ số mảng phải trừ một哦
            int i = booking[0] - 1;
            int j = booking[1] - 1;
            int val = booking[2];
            // Cho đoạn nums[i..j] tăng val
            df.increment(i, j, val);
        }
        // Trả về mảng kết quả cuối cùng
        return df.result();
    }
}
```

Bài này就 giải xong.

Còn một bài rất tương tự là LeetCode 1094 「Đi xe chung」, tôi mô tả đơn giản đề bài:

Bạn là tài xế lái xe buýt, tải trọng tối đa của xe là `capacity`, dọc đường phải đi qua若干 trạm, cho bạn một bảng hành trình hành khách `int[][] trips`, trong đó `trips[i] = [num, start, end]` đại diện có `num` hành khách muốn lên xe từ trạm `start`, xuống xe ở trạm `end`, hãy tính liệu có thể một lần chở hết tất cả hành khách không (không được vượt quá tải trọng tối đa `capacity`).

Chữ ký hàm như sau:

```java
boolean carPooling(int[][] trips, int capacity);
```

Ví dụ nhập:

```
trips = [[2,1,5],[3,3,7]], capacity = 4
```

Chuyện này không thể một lần chở hết, vì `trips[1]` nhiều nhất chỉ lên được 2 người, nếu không xe sẽ quá tải.

Tin rằng bạn đã có thể liên tưởng đến技巧 mảng hiệu: **`trips[i]` đại diện một nhóm thao tác theo đoạn, hành khách lên xuống xe就相当于 cộng trừ theo đoạn của mảng; chỉ cần phần tử trong mảng kết quả đều nhỏ hơn `capacity`,就说明 có thể chở hết tất cả hành khách mà không quá tải**.

Nhưng vấn đề là, độ dài mảng hiệu (số lượng trạm) hẳn là bao nhiêu? Đề không cho trực tiếp, nhưng cho phạm vi giá trị dữ liệu:

```java
0 <= trips[i][1] < trips[i][2] <= 1000
```

Số hiệu trạm bắt đầu từ 0, nhiều nhất đến 1000, tức nhiều nhất có 1001 trạm, vậy độ dài mảng hiệu của chúng ta có thể设 trực tiếp là 1001, như vậy chỉ số vừa khéo bao phủ số hiệu tất cả trạm:

```java
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        // Nhiều nhất có 1001 trạm
        int[] nums = new int[1001];

        // Dựng giải pháp hiệu
        Difference df = new Difference(nums);

        for (int[] trip : trips) {
            // Số lượng hành khách
            int val = trip[0];

            // Trạm trip[1] hành khách lên xe
            int i = trip[1];

            // Trạm trip[2] hành khách đã xuống xe,
            // tức đoạn hành khách trên xe là [trip[1], trip[2] - 1]
            int j = trip[2] - 1;

            // Tiến hành thao tác theo đoạn
            df.increment(i, j, val);
        }

        int[] res = df.result();

        // Xe từ đầu đến cuối都不应该 quá tải
        for (int i = 0; i < res.length; i++) {
            if (capacity < res[i]) {
                return false;
            }
        }
        return true;
    }
}
```
