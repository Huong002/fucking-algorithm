Khi xử lý vấn đề liên quan mảng và danh sách liên kết, kỹ thuật hai con trỏ thường được dùng, kỹ thuật hai con trỏ chủ yếu chia hai loại:**con trỏ trái-phải** và**con trỏ nhanh-chậm**.

Cái gọi là con trỏ trái-phải, chính là hai con trỏ hướng vào nhau mà đi hoặc quay lưng vào nhau mà đi; mà cái gọi là con trỏ nhanh-chậm, chính là hai con trỏ cùng hướng mà đi, một nhanh một chậm.

Với danh sách đơn, đa sốkỹ thuật đều thuộc con trỏ nhanh-chậm, [Sáucông thức giải đề danh sách đơn](https://labuladong.online/algo/essential-technique/linked-list-skills-summary/) đều bao hàm, ví nhưkiểm tra vòng danh sách, nút danh sách thứ `K` từ dưới đếm lên, v.v., chúng đều thông qua một con trỏ nhanh `fast` và một con trỏ chậm `slow` phối hợp hoàn thành nhiệm vụ.

Trong mảng cũng không có thực sự ý nghĩa 上 con trỏ, nhưng chúng ta có thể coi chỉ số làm con trỏ trong mảng, như vậy cũng có thể trong mảng施 triển kỹ thuật hai con trỏ, **bài này chủ yếugiảng thuật toán hai con trỏ liên quan mảng**.

## Một,kỹ thuật con trỏ nhanh-chậm

### Sửa tại chỗ

**Trong bài toán mảng khá thường gặp kỹ thuật con trỏ nhanh-chậm, là bắt bạn sửa mảng tại chỗ**.

Ví như xem LeetCode 26 "Xóa trùng trong mảng có thứ tự", bắt bạn khử trùng lặp mảng có thứ tự:

<Problem slug="remove-duplicates-from-sorted-array" />

Chữ ký hàm như sau:

```java
int removeDuplicates(int[] nums);
```

Giải thích đơn giản là gì sửa tại chỗ:

Nếu không phải sửa tại chỗ, chúng ta trực tiếp new một mảng `int[]`, đem phần tử sau khử trùng lặp 放 vào mảng mới này, rồi trả về mảng mới này là được.

Nhưng bây giờ đề bắt bạn xóa tại chỗ, không cho new mảng mới, chỉ có thể trên mảng gốc thao tác, rồi trả về một độ dài, như vậy là có thể thông qua độ dài trả về và mảng gốc nhận được chúng ta khử trùng lặp xong phần tử có những gì.

Do mảng đã sắp xếp, nên phần tử trùng nhất định连 cùng nhau, tìm ra chúng không khó. Nhưng nếu mỗi tìm được một phần tử trùng sẽ ngay lập tức xóa tại chỗ nó, do xóa phần tử trong mảng liên quan di chuyển dữ liệu, độ phức tạp thời gian toàn bộ sẽ đạt $O(N^2)$.

Giải hiệu quả bài này sẽ cần dùngkỹ thuật con trỏ nhanh-chậm:

Chúng ta để con trỏ chậm `slow` đi phía sau, con trỏ nhanh `fast` đi phía trước dò đường, tìm được một phần tử không trùng sẽ gán cho `slow`並 để `slow` tiến một bước.

Như vậy, sẽ đảm bảo `nums[0..slow]` đều là phần tử không trùng, khi con trỏ `fast` duyệt hết toàn bộ mảng `nums` xong, `nums[0..slow]` chính là kết quả sau khử trùng lặp của toàn bộ mảng.

Xem code:

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) {
            return 0;
        }
        int slow = 0, fast = 0;
        while (fast < nums.length) {
            if (nums[fast] != nums[slow]) {
                slow++;
                // Duy trì nums[0..slow] không trùng
                nums[slow] = nums[fast];
            }
            fast++;
        }
        // Độ dài mảng là chỉ số + 1
        return slow + 1;
    }
}
```

Mở rộng đơn giản chút, xem LeetCode 83 "Xóa trùng trong danh sách liên kết có thứ tự", nếu cho bạn một danh sách đơn có thứ tự, khử trùng lặp thế nào?

Thực ra khử trùng lặp với mảng giống hệt nhau, duy nhất khác biệt là đem thao tác gán mảng biến thành thao tác con trỏ mà thôi, bạn对照 code trước đó xem:

```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) return null;
        ListNode slow = head, fast = head;
        while (fast != null) {
            if (fast.val != slow.val) {
                // nums[slow] = nums[fast];
                slow.next = fast;
                // slow++;
                slow = slow.next;
            }
            // fast++
            fast = fast.next;
        }
        // Ngắt kết nối với phần tử trùng phía sau
        slow.next = null;
        return head;
    }
}
```

**Ngoài việc bắt bạn khử trùng lặp trong mảng/danh sách có thứ tự, đề còn có thể bắt bạn với một số phần tử trong mảng tiến hành "xóa tại chỗ"**.

Ví như LeetCode 27 "Xóa phần tử", xem đề:

<Problem slug="remove-element" />

```java
// Chữ ký hàm như sau
int removeElement(int[] nums, int val);
```

Đề yêu cầu chúng ta đem tất cả phần tử giá trị `val` trong `nums` xóa tại chỗ, vẫn cần dùngkỹ thuật con trỏ nhanh-chậm:

Nếu `fast` gặp phần tử giá trị `val`则 trực tiếp bỏ qua, nếu không sẽ gán cho con trỏ `slow`, 並 để `slow` tiến một bước.

Chuyện này và vấn đề khử trùng lặp mảng nói trước đóý tưởng giải hoàn toàn giống nhau, xem trực tiếp code:

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int fast = 0, slow = 0;
        while (fast < nums.length) {
            if (nums[fast] != val) {
                nums[slow] = nums[fast];
                slow++;
            }
            fast++;
        }
        return slow;
    }
}
```

Cài đặt xong hàm `removeElement` này, tiếp theo xem LeetCode 283 "Di chuyển số 0":

Cho bạn nhập một mảng `nums`, hãy bạn**sửa tại chỗ**, đem tất cả phần tử giá trị 0 trong mảng chuyển xuống cuối mảng, chữ ký hàm như sau:

```java
void moveZeroes(int[] nums);
```

Ví dụ cho bạn nhập `nums = [0, 1, 4, 0, 2]`, thuật toán của bạn không có giá trị trả về, nhưng sẽ đem mảng `nums` sửa tại chỗ thành `[1, 4, 2, 0, 0]`.

Kết hợp mấy đề nói trước đó, bạn có phải đã có đáp án không?

### Cửa sổ trượt (Sliding Window)

Một loại lớn đề con trỏ nhanh-chậm khác trong mảng chính là "thuật toán cửa sổ trượt". Tôi trong một bài khác [giải chi tiết khung cốt lõi thuật toán cửa sổ trượt](https://labuladong.online/algo/essential-technique/sliding-window-framework/) đã cho khung code cửa sổ trượt:

```java
// Mã giả khung thuật toán cửa sổ trượt
int left = 0, right = 0;

while (right < nums.size()) {
    // Tăng cửa sổ
    window.addLast(nums[right]);
    right++;

    while (window needs shrink) {
        // Thu nhỏ cửa sổ
        window.removeFirst(nums[left]);
        left++;
    }
}
```

Đề cụ thể bài này sẽ không lặp lại, chỗ này chỉ nhấn mạnh đặc tính con trỏ nhanh-chậm của thuật toán cửa sổ trượt:

Con trỏ `left` ở sau, con trỏ `right` ở trước, phần giữa hai con trỏ chính là "cửa sổ", thuật toán thông qua mở rộng và thu nhỏ "cửa sổ" để giải một số vấn đề.

## Hai, thuật toán thường dùng của con trỏ trái-phải

### Tìm kiếm nhị phân

Tôi trong một bài khác [giải chi tiết khung tìm kiếm nhị phân](https://labuladong.online/algo/essential-technique/binary-search-framework/) có thảo luận chi tiết vấn đề chi tiết code tìm kiếm nhị phân, chỗ này chỉ viết thuật toán nhị phân đơn giản nhất, nhằm nổi bật đặc tính hai con trỏ của nó:

```java
int binarySearch(int[] nums, int target) {
    // Hai con trỏ một trái một phải hướng vào nhau mà đi
    int left = 0, right = nums.length - 1;
    while(left <= right) {
        int mid = (right + left) / 2;
        if(nums[mid] == target)
            return mid;
        else if (nums[mid] < target)
            left = mid + 1;
        else if (nums[mid] > target)
            right = mid - 1;
    }
    return -1;
}
```

### Tổng của `n` số

Xem LeetCode 167 "Tổng hai số II":

<Problem slug="two-sum-ii-input-array-is-sorted" />

Chỉ cần mảng có thứ tự, sẽ hẳn nghĩ đếnkỹ thuật hai con trỏ. cách giải bài này hơi tương tự tìm kiếm nhị phân, thông qua điều chỉnh `left` và `right` là có thể điều chỉnh kích thước của `sum`:

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        // Hai con trỏ một trái một phải hướng vào nhau mà đi
        int left = 0, right = numbers.length - 1;
        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                // Chỉ số đề yêu cầu đếm từ 1
                return new int[]{left + 1, right + 1};
            } else if (sum < target) {
                // để sum lớn hơn chút
                left++;
            } else if (sum > target) {
                // để sum nhỏ hơn chút
                right--;
            }
        }
        return new int[]{-1, -1};
    }
}
```

Tôi trong một bài khác [Một hàmxử gọn mọi vấn đề nSum](https://labuladong.online/algo/practice-in-action/nsum/) cũng vận dụngkỹ thuật con trỏ trái-phải tương tự cho ra mộtý tưởng tổng quát của vấn đề `nSum`, bản chất lợi dụng cũng làkỹ thuật hai con trỏ.

### Đảo mảng

Ngôn ngữ lập trình thường đều sẽ cung cấp hàm `reverse`, thực ra nguyên lý hàm này rất đơn giản, LeetCode 344 "Đảo chuỗi" chính là nhu cầu tương tự, bắt bạn đảo một mảng ký tự kiểu `char[]`, chúng ta xem trực tiếp code:

```java
void reverseString(char[] s) {
    // Hai con trỏ một trái một phải hướng vào nhau mà đi
    int left = 0, right = s.length - 1;
    while (left < right) {
        // Hoán đổi s[left] và s[right]
        char temp = s[left];
        s[left] = s[right];
        s[right] = temp;
        left++;
        right--;
    }
}
```

Về vấn đề nâng cao hơn của lật mảng, có thể xem [Duyệt hoa hòe của mảng hai chiều](https://labuladong.online/algo/practice-in-action/2d-array-traversal-summary/).

### kiểm tra chuỗipalindrome

Chuỗipalindrome chính là chuỗi đọc xuôi và đọc ngược đều giống nhau. Ví dụ chuỗi `aba` và `abba` đều là chuỗipalindrome, vì chúng đối xứng, đảo lại vẫn giống bản thân; ngược lại, chuỗi `abac` thì không phải chuỗipalindrome.

Bây giờ bạn hẳn có thể cảm thấy vấn đề chuỗipalindrome và con trỏ trái-phải chắc chắn có liên hệ密 cắt, ví như bắt bạnkiểm tra một chuỗi có phải chuỗipalindrome không, bạn có thể viết ra đoạn code sau:

```java
boolean isPalindrome(String s) {
    // Hai con trỏ một trái một phải hướng vào nhau mà đi
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

Vậy tiếp theo tôi nâng chút độ khó, cho bạn một chuỗi, bắt bạn dùngkỹ thuật hai con trỏ từ đó tìm ra chuỗipalindrome dài nhất, bạn sẽ làm không?

Đây chính là LeetCode 5 "Chuỗipalindrome dài nhất":

<Problem slug="longest-palindromic-substring" />

Chữ ký hàm như sau:

```java
String longestPalindrome(String s);
```

Điểm khó tìm chuỗipalindrome nằm ở, độ dài chuỗipalindrome có thể là lẻ cũng có thể là chẵn, cốt lõi giải vấn đề này là**kỹ thuật hai con trỏ lan rộng từ trung tâm ra hai đầu**.

Nếu độ dài chuỗipalindrome là lẻ, 則 nó có một ký tự trung tâm; nếu độ dài chuỗipalindrome là chẵn, 則 có thể coi nó có hai ký tự trung tâm. Nên chúng ta có thể先 cài đặt một hàm như sau:

```java
// Tìm trong s chuỗipalindrome dài nhất lấy s[l] và s[r] làm trung tâm
String palindrome(String s, int l, int r) {
    // 防 chỉ số vượt giới hạn
    while (l >= 0 && r < s.length()
            && s.charAt(l) == s.charAt(r)) {
        // Hai con trỏ, mở rộng sang hai bên
        l--; r++;
    }
    // Trả về chuỗipalindrome dài nhất lấy s[l] và s[r] làm trung tâm
    return s.substring(l + 1, r);
}
```

Như vậy, nếu nhập `l` và `r` giống nhau, sẽ tương đương với tìm chuỗipalindrome độ dài lẻ, nếu nhập `l` và `r` kề nhau, 則tương đương với tìm chuỗipalindrome độ dài chẵn.

Vậy trở lại vấn đề chuỗipalindrome dài nhất,ý tưởng giải đại khái chính là:

```python
for 0 <= i < len(s):
    tìm chuỗipalindrome lấy s[i] làm trung tâm
    tìm chuỗipalindrome lấy s[i] và s[i+1] làm trung tâm
    cập nhật đáp án
```

Dịch thành code, là có thể giải vấn đề chuỗi conpalindrome dài nhất này:

```java
String longestPalindrome(String s) {
    String res = "";
    for (int i = 0; i < s.length(); i++) {
        // Chuỗi conpalindrome dài nhất lấy s[i] làm trung tâm
        String s1 = palindrome(s, i, i);
        // Chuỗi conpalindrome dài nhất lấy s[i] và s[i+1] làm trung tâm
        String s2 = palindrome(s, i, i + 1);
        // res = longest(res, s1, s2)
        res = res.length() > s1.length() ? res : s1;
        res = res.length() > s2.length() ? res : s2;
    }
    return res;
}
```

Bạn hẳn có thể phát hiện con trỏ trái-phải mà chuỗipalindrome dài nhất dùng và con trỏ trái-phải của đề trước có chút khác: con trỏ trái-phải trước đó đều từ hai đầu hướng vào nhau mà đi vào giữa, mà vấn đề chuỗipalindrome lại là để con trỏ trái-phải từ trung tâm mở rộng ra hai đầu. Có điều tình huống này cũng sẽ loại vấn đề chuỗipalindrome này sẽ gặp, nên tôi cũng归 nó vào con trỏ trái-phải.
