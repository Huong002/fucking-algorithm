Kỹ thuật tổng tiền tố (prefix sum) phù hợp để tính nhanh, thường xuyên tổng các phần tử trong một đoạn chỉ số.

## Tổng tiền tố trong mảng một chiều

Xem trước một ví dụ, LeetCode 303 「Truy vấn tổng theo đoạn - Mảng bất biến」, bắt bạn tính tổng phần tử trong đoạn của mảng, đây là một bài tổng tiền tố chuẩn:

<Problem slug="range-sum-query-immutable" />

```java
// Đề bài yêu cầu bạn cài đặt một lớp như sau
class NumArray {

    public NumArray(int[] nums) {}

    // Truy vấn tổng dồn của đoạn đóng [left, right]
    public int sumRange(int left, int right) {}
}
```

Hàm `sumRange` cần tính và trả về tổng phần tử trong một đoạn chỉ số, người chưa học tổng tiền tố có thể viết code như sau:

```java
class NumArray {
    // Mảng tổng tiền tố
    private int[] preSum;

    // Nhập một mảng, dựng tổng tiền tố
    public NumArray(int[] nums) {
        // preSum[0] = 0, tiện cho việc tính tổng dồn
        preSum = new int[nums.length + 1];
        // Tính tổng dồn của nums
        for (int i = 1; i < preSum.length; i++) {
            preSum[i] = preSum[i - 1] + nums[i - 1];
        }
    }

    // Truy vấn tổng dồn của đoạn đóng [left, right]
    public int sumRange(int left, int right) {
        return preSum[right + 1] - preSum[left];
    }
}
```

思路 cốt lõi là chúng ta new ra một mảng mới `preSum`, `preSum[i]` ghi lại tổng dồn của `nums[0..i-1]`, xem hình $10 = 3 + 5 + 2$:

![](https://labuladong.online/algo/images/difference/1.jpeg)

Nhìn mảng `preSum` này, nếu tôi muốn求 tổng tất cả phần tử trong đoạn chỉ số `[1, 4]`, có thể得出 thông qua `preSum[5] - preSum[1]`.

Như vậy, hàm `sumRange` vẻn vẹn cần làm một phép trừ, tránh việc mỗi lần for lặp gọi, độ phức tạp thời gian xấu nhất là hằng số $O(1)$.

Kỹ thuật này vận dụng trong đời sống cũng khá rộng, ví dụ, lớp các bạn có若干 bạn học, mỗi bạn có một điểm thi cuối kỳ (thang 100), vậy hãy实现 một API, nhập vào đoạn điểm bất kỳ, trả về có bao nhiêu bạn có điểm trong đoạn này.

Vậy, bạn có thể先 thông qua cách sắp xếp đếm (counting sort) để tính mỗi điểm cụ thể có mấy bạn, rồi lợi dụng kỹ thuật tổng tiền tố để实现 API truy vấn theo đoạn điểm:

```java
// Lưu điểm của tất cả bạn học
int[] scores;
// Bài thi thang 100 điểm
int[] count = new int[100 + 1];
// Ghi lại mỗi điểm có mấy bạn
for (int score : scores)
    count[score]++;
// Dựng tổng tiền tố
for (int i = 1; i < count.length; i++)
    count[i] = count[i] + count[i-1];
// Lợi dụng mảng tổng tiền tố count này để truy vấn theo đoạn điểm
```

Tiếp theo, chúng ta xem思路 tổng tiền tố vận dụng trong mảng hai chiều thế nào.

## Tổng tiền tố trong ma trận hai chiều

Đây là LeetCode 304 「Truy vấn tổng theo vùng 2D - Ma trận bất biến」, thực ra tương tự bài trên, bài trên bắt bạn tính tổng phần tử của mảng con, bài này bắt bạn tính tổng phần tử của ma trận con trong ma trận hai chiều:

<Problem slug="range-sum-query-2d-immutable" />

Đương nhiên, bạn có thể dùng một vòng for lồng nhau để duyệt ma trận này, nhưng như vậy độ phức tạp thời gian của hàm `sumRegion` sẽ cao,格局 thuật toán của bạn就低了.

Chú ý tổng phần tử của ma trận con bất kỳ có thể chuyển thành phép toán tổng phần tử của mấy ma trận lớn xung quanh nó:

![](https://labuladong.online/algo/images/presum/5.jpeg)

Mà bốn ma trận lớn này có một đặc điểm chung, là góc trên-trái đều là gốc `(0, 0)`.

Vậy思路 tốt hơn để làm bài này rất tương tự tổng tiền tố trong mảng một chiều, chúng ta có thể维护 một mảng `preSum` hai chiều, chuyên ghi lại tổng phần tử của ma trận lấy gốc làm đỉnh, là có thể dùng vài phép cộng trừ tính ra tổng phần tử của bất kỳ ma trận con nào:

```java
class NumMatrix {
    // preSum[i][j] ghi lại tổng phần tử của ma trận [0, 0, i-1, j-1]
    private int[][] preSum;

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        if (m == 0 || n == 0) return;
        // Dựng ma trận tổng tiền tố
        preSum = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // Tính tổng phần tử của mỗi ma trận [0, 0, i, j]
                preSum[i][j] = preSum[i-1][j] + preSum[i][j-1] + matrix[i - 1][j - 1] - preSum[i-1][j-1];
            }
        }
    }

    // Tính tổng phần tử của ma trận con [x1, y1, x2, y2]
    public int sumRegion(int x1, int y1, int x2, int y2) {
        // Tổng ma trận mục tiêu thu được từ phép toán của bốn ma trận kề nhau
        return preSum[x2+1][y2+1] - preSum[x1][y2+1] - preSum[x2+1][y1] + preSum[x1][y1];
    }
}
```

Như vậy, độ phức tạp thời gian của hàm `sumRegion` cũng được tối ưu bằng kỹ thuật tổng tiền tố xuống $O(1)$, đây là思路 điển hình 「đổi không gian lấy thời gian」.

<visual slug='range-sum-query-2d-immutable' >

Bạn có thể mở hình động可视 hóa bên dưới, bấm nhiều lần <code type="click">preSum[i][j] = ...</code> dòng này, là có thể thấy quá trình tính mảng <code type="click">preSum</code>, bấm nhiều lần <code type="click">console.log</code> dòng này, là có thể thấy lệnh gọi hàm <code type="click">sumRegion</code>:

Kỹ thuật tổng tiền tố就讲 đến đây, hẳn phải nói kỹ thuật thuật toán này là会者不难难者不会, vận dụng thực tế vẫn phải多培养 tính linh hoạt tư duy của mình,做到一眼 nhìn ra đề bài là một bài toán tổng tiền tố.

## Mở rộng

Kỹ thuật tổng tiền tố mà bài này讲 là lợi dụng mảng `preSum` tính trước để tính nhanh tổng phần tử trong đoạn chỉ số, nhưng thực tế nó không chỉ giới hạn ở求 tổng, cũng có thể dùng để tính nhanh giá trị lớn nhất, nhỏ nhất, tích trong đoạn, v.v.

Hơn nữa mảng tổng tiền tố thường kết hợp với cấu trúc dữ liệu khác hoặc技巧 thuật toán khác, tôi sẽ在 [Bài tập高频技巧 tổng tiền tố](https://labuladong.online/algo/problem-set/perfix-sum/) kết hợp bài tập để讲.

**Còn một vấn đề quan trọng: tiền đề dùng kỹ thuật tổng tiền tố là mảng gốc `nums` sẽ không thay đổi**.

Nếu một phần tử nào đó trong mảng gốc thay đổi, vậy giá trị phía sau phần tử đó trong mảng `preSum` sẽ失效, cần tốn lại $O(n)$ thời gian để tính, chuyện này就和解法暴力 thông thường không khác mấy.

Nên trong cảnh mảng phần tử可变, chúng ta không thể dùng kỹ thuật tổng tiền tố, mà dùng cấu trúc dữ liệu như [Cây đoạn (segment tree)](https://labuladong.online/algo/data-structure/segment-tree-implement/) để xử lý truy vấn đoạn và cập nhật động.
