## Xoay ma trận theo/ngược chiều kim đồng hồ

Xoay mảng hai chiều là đề thi viết thường gặp, LeetCode 48 「Xoay hình ảnh」 chính là một đạo rất kinh điển:

<Problem slug="rotate-image" />

Đề rất dễ hiểu, chính là bắt bạn把 một ma trận hai chiều xoay theo chiều kim đồng hồ 90 độ, **điểm khó nằm ở要 「tại chỗ」 sửa đổi**, chữ ký hàm như sau:

```java
void rotate(int[][] matrix)
```

Làm sao 「tại chỗ」 xoay ma trận hai chiều? Hơi nghĩ chút, cảm giác thao tác起來非常 phức tạp, có thể要设 cơ chế thuật toán巧妙 để 「từng vòng từng vòng」 xoay ma trận:

![](https://labuladong.online/algo/images/2d-array/1.png)

**Nhưng thực tế, bài này không thể đi đường寻常**, trước khi讲解法巧妙, chúng ta xem trước một đạo đề thuật toán Google từng考 qua để khởi động:

Cho bạn một chuỗi `s` chứa若干 từ và dấu cách, hãy viết một thuật toán, **tại chỗ** đảo ngược thứ tự tất cả từ.

Ví dụ, cho bạn nhập một chuỗi như sau:

```shell
s = "hello world labuladong"
```

Thuật toán của bạn cần **tại chỗ** đảo ngược thứ tự từ trong chuỗi này:

```shell
s = "labuladong world hello"
```

Cách thông thường là把 `s`按 dấu cách `split` thành若干 từ, rồi `reverse` thứ tự những từ này, cuối cùng把 những từ này `join` thành câu. Nhưng cách này dùng không gian thêm,并不是 「tại chỗ đảo ngược」 từ.

**Cách làm đúng là,先把 toàn bộ chuỗi `s` đảo ngược**:

```shell
s = "gnodalubal dlrow olleh"
```

**Rồi把 mỗi từ分别 đảo ngược**:

```shell
s = "labuladong world hello"
```

Như vậy,就实现 mục đích tại chỗ đảo ngược thứ tự tất cả từ. LeetCode 151 「Đảo từ trong chuỗi」 chính là vấn đề tương tự, bạn có thể tiện thể đi làm một chút.

技巧 nhỏ trên còn có thể包装 thêm, ví dụ bạn có thể xem LeetCode 61 「Xoay danh sách liên kết」: cho bạn một danh sách đơn, bắt bạn xoay danh sách,把 mỗi nút của danh sách di chuyển sang phải `k` vị trí.

Ví dụ nhập danh sách đơn `1 -> 2 -> 3 -> 4 -> 5`, `k = 2`, thuật toán của bạn cần trả về `4 -> 5 -> 1 -> 2 -> 3`, tức把 mỗi nút danh sách di chuyển sang phải 2 vị trí.

Bài này, đừng thật ngốc nghếch từng cái từng cái đi di chuyển nút danh sách, tôi dịch cho bạn, thực ra chính là把 `k` nút sau của danh sách di chuyển lên đầu danh sách嘛, phản ứng过来 chưa?

Chưa phản ứng过来, vậy gợi ý thêm chút,，把 `k` nút sau di chuyển lên đầu danh sách, thực ra chính là bắt bạn把 `n - k` nút trước và `k` nút sau tại chỗ lật ngược, đúng không?

Như vậy, có phải cùng đạo lý với tại chỗ lật từ trong chuỗi nói trước đó không? Bạn chỉ cần先把 toàn bộ danh sách đảo ngược, rồi把 `n - k` nút trước và `k` nút sau分别 đảo ngược,就得到 kết quả.

Đương nhiên, bài này có một số chi tiết nhỏ, ví dụ `k` này có thể lớn hơn độ dài danh sách, vậy bạn cần先求 độ dài danh sách `n`, rồi lấy dư `k = k % n`, như vậy `k` sẽ không lớn hơn độ dài danh sách, mà kết quả cuối cùng thu được cũng đúng.

Có thời gian tự đi làm bài này吧,比较 đơn giản, chỗ này tôi就不贴 code.

Tôi讲 hai bài trên mục đích là gì?

**Nhằm说明, có lúc tư duy thông thường mà chúng ta拍脑袋, trong mắt máy tính có thể并不是优雅 nhất; nhưng tư duy mà máy tính thấy优雅 nhất, với chúng ta lại không trực quan như vậy**. Có lẽ đây chính là chỗ quyến rũ của thuật toán吧.

Trở lại vấn đề xoay ma trận hai chiều theo chiều kim đồng hồ nói trước đó,思路 thông thường chính là đi tìm quy luật ánh xạ của tọa độ gốc và tọa độ sau xoay, nhưng chúng ta có thể让 tư duy nhảy vọt, thử把 ma trận tiến hành đảo ngược, đối xứng gương, v.v. thao tác, có thể xuất hiện突破口 mới.

**Chúng ta có thể先把 ma trận `n x n` `matrix`按 đường chéo từ trên-trái xuống dưới-phải tiến hành đối xứng gương**:

![](https://labuladong.online/algo/images/2d-array/2.jpeg)

**Rồi với mỗi hàng của ma trận tiến hành đảo ngược**:

![](https://labuladong.online/algo/images/2d-array/3.jpeg)

**Phát hiện kết quả chính là kết quả `matrix` xoay theo chiều kim đồng hồ 90 độ**:

![](https://labuladong.online/algo/images/2d-array/4.jpeg)

把思路 trên dịch thành code, là có thể giải bài này:

```java
class Solution {
    // Xoay ma trận hai chiều tại chỗ theo chiều kim đồng hồ 90 độ
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        // Trước沿 đường chéo đối xứng gương ma trận hai chiều
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                // swap(matrix[i][j], matrix[j][i]);
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }
        // Rồi đảo ngược mỗi hàng của ma trận hai chiều
        for (int[] row : matrix) {
            reverse(row);
        }
    }

    // Đảo ngược mảng một chiều
    void reverse(int[] arr) {
        int i = 0, j = arr.length - 1;
        while (j > i) {
            // swap(arr[i], arr[j]);
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
            i++;
            j--;
        }
    }
}
```

Khẳng định có độc giả sẽ hỏi, nếu chưa từng làm bài này, sao có thể nghĩ ra思路 này?

Đúng, chưa từng làm loại đề này,确实不好 nghĩ ra思路 này, nhưng bạn đây chẳng phải làm qua sao? Cái gọi là会者不难难者不会, đời này của bạn估计都忘不掉.

**既然说到 chỗ này, chúng ta có thể发散 một chút, làm sao把 ma trận xoay ngược chiều kim đồng hồ 90 độ**?

思路 tương tự, chỉ cần thông qua đường chéo còn lại đối xứng gương ma trận, rồi đảo ngược mỗi hàng,就得到 kết quả xoay ma trận ngược chiều kim đồng hồ:

![](https://labuladong.online/algo/images/2d-array/5.jpeg)

Dịch thành code như sau:

```java
class Solution {

    // Xoay ma trận hai chiều tại chỗ ngược chiều kim đồng hồ 90 độ
    public void rotate2(int[][] matrix) {
        int n = matrix.length;
        // 沿 đường chéo từ dưới-trái lên trên-phải đối xứng gương ma trận hai chiều
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n - i; j++) {
                // swap(matrix[i][j], matrix[n-j-1][n-i-1])
                int temp = matrix[i][j];
                matrix[i][j] = matrix[n - j - 1][n - i - 1];
                matrix[n - j - 1][n - i - 1] = temp;
            }
        }
        // Rồi đảo ngược mỗi hàng của ma trận hai chiều
        for (int[] row : matrix) {
            reverse(row);
        }
    }

    void reverse(int[] arr) {
        // Xem bài trên
    }
}
```

## Duyệt xoắn ốc của ma trận

Tiếp theo chúng ta讲 LeetCode 54 「Ma trận xoắn ốc」, xem mảng hai chiều có thể duyệt hoa hòe thế nào:

<Problem slug="spiral-matrix" />

```java
// Chữ ký hàm như sau
List<Integer> spiralOrder(int[][] matrix)
```

**思路 cốt lõi giải đề là按 thứ tự phải, dưới, trái, trên duyệt mảng, và dùng bốn biến khoanh biên chưa duyệt**:

![](https://labuladong.online/algo/images/2d-array/6.png)

Theo duyệt xoắn ốc, biên tương ứng sẽ co lại, cho đến khi duyệt xoắn ốc hết toàn bộ mảng:

![](https://labuladong.online/algo/images/2d-array/7.png)

Chỉ cần có思路 này, dịch ra code就很容易:

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int upper_bound = 0, lower_bound = m - 1;
        int left_bound = 0, right_bound = n - 1;
        List<Integer> res = new LinkedList<>();
        // res.size() == m * n则 duyệt hết toàn bộ mảng
        while (res.size() < m * n) {
            if (upper_bound <= lower_bound) {
                // Ở đỉnh duyệt từ trái sang phải
                for (int j = left_bound; j <= right_bound; j++) {
                    res.add(matrix[upper_bound][j]);
                }
                // Biên trên dời xuống
                upper_bound++;
            }

            if (left_bound <= right_bound) {
                // Ở phải duyệt từ trên xuống dưới
                for (int i = upper_bound; i <= lower_bound; i++) {
                    res.add(matrix[i][right_bound]);
                }
                // Biên phải dời sang trái
                right_bound--;
            }

            if (upper_bound <= lower_bound) {
                // Ở đáy duyệt từ phải sang trái
                for (int j = right_bound; j >= left_bound; j--) {
                    res.add(matrix[lower_bound][j]);
                }
                // Biên dưới dời lên
                lower_bound--;
            }

            if (left_bound <= right_bound) {
                // Ở trái duyệt từ dưới lên trên
                for (int i = lower_bound; i >= upper_bound; i--) {
                    res.add(matrix[i][left_bound]);
                }
                // Biên trái dời sang phải
                left_bound++;
            }
        }
        return res;
    }
}
```

```java
// Chữ ký hàm như sau
```

Có铺垫 trên, sửa chút code là có thể hoàn thành bài này:

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] matrix = new int[n][n];
        int upper_bound = 0, lower_bound = n - 1;
        int left_bound = 0, right_bound = n - 1;
        // Số cần điền vào ma trận
        int num = 1;

        while (num <= n * n) {
            if (upper_bound <= lower_bound) {
                // Ở đỉnh duyệt từ trái sang phải
                for (int j = left_bound; j <= right_bound; j++) {
                    matrix[upper_bound][j] = num++;
                }
                // Biên trên dời xuống
                upper_bound++;
            }

            if (left_bound <= right_bound) {
                // Ở phải duyệt từ trên xuống dưới
                for (int i = upper_bound; i <= lower_bound; i++) {
                    matrix[i][right_bound] = num++;
                }
                // Biên phải dời sang trái
                right_bound--;
            }

            if (upper_bound <= lower_bound) {
                // Ở đáy duyệt từ phải sang trái
                for (int j = right_bound; j >= left_bound; j--) {
                    matrix[lower_bound][j] = num++;
                }
                // Biên dưới dời lên
                lower_bound--;
            }

            if (left_bound <= right_bound) {
                // Ở trái duyệt từ dưới lên trên
                for (int i = lower_bound; i >= upper_bound; i--) {
                    matrix[i][left_bound] = num++;
                }
                // Biên trái dời sang phải
                left_bound++;
            }
        }
        return matrix;
    }
}
```
