##思路解法

Trước ôn lại bài lịch sử liên quan thuật toán ngẫu nhiên của ta:

Bài trước [thiết kế cấu trúc dữ liệu xóa ngẫu nhiên](https://labuladong.online/algo/data-structure/random-set/) chủ yếu考察 dùng cấu trúc dữ liệu, mỗi lần chuyển phần tử tới đuôi mảng rồi xóa, có thể tránh搬移 dữ liệu.

Bài trước [bàn thuật toán ngẫu nhiên trong game](https://labuladong.online/algo/frequency-interview/random-algorithm/)讲 kinh điển 「thuật toán抽样 hồ nước」, dùng phép toán đơn giản,抽等 xác suất phần tử trong序列 vô hạn.

Bài trước [技巧笔试 thuật toán](https://labuladong.online/algo/other-skills/tips-in-exam/) tôi còn chia sẻ một技巧lấy điểm dùng xác suất tối đa hóa tỉ lệ qua test.

**Nhưng旧文 trên không giải được vấn đề bài này nêu, ngược lại bài trước [技巧 tổng tiền tố](https://labuladong.online/algo/data-structure/prefix-sum/) cộng [chi tiết tìm kiếm nhị phân](https://labuladong.online/algo/essential-technique/binary-search-framework/) có thể giải thuật toán chọn ngẫu nhiên theo trọng số**.

Thuật toán ngẫu nhiên này với技巧 tổng tiền tố và技巧 tìm kiếm nhị phân能扯 quan hệ gì?且听 tôi慢慢道来.

Giả sử mảng trọng số input bạn là `w = [1,3,2,1]`, ta muốn xác suất符合 trọng số, vậy có thể trừu tượng một chút, theo trọng số vẽ một đoạn thẳng màu thế này:

Nếu tôi ném ngẫu nhiên một hòn đá lên đoạn thẳng, đá rơi màu nào, tôi就 chọn chỉ số trọng số màu đó tương ứng, vậy xác suất mỗi chỉ số被选是不是就关联 trọng số?

**Nên, bạn再 nhìn kỹ đoạn màu này giống gì? Đây chẳng phải [mảng tổng tiền tố](https://labuladong.online/algo/data-structure/prefix-sum/) sao**:

Vậy tiếp, mô phỏng ném đá lên đoạn thẳng thế nào?

Đương nhiên là số ngẫu nhiên, ví dụ mảng tổng tiền tố `preSum` trên, phạm vi取值 `[1, 7]`, vậy tôi sinh một số ngẫu nhiên trong khoảng này `target = 5`,就好像 ném ngẫu nhiên một hòn đá trong đoạn này:

Còn một vấn đề, `preSum`中并没有 phần tử 5, ta nên chọn phần tử nhỏ nhất lớn hơn 5, chính là 6, tức chỉ số 3 của mảng `preSum`:

![](https://labuladong.online/algo/images/random-weight/4.jpeg)

**Tìm nhanh phần tử nhỏ nhất lớn bằng giá trị mục tiêu trong mảng thế nào? [Thuật toán tìm kiếm nhị phân](https://labuladong.online/algo/essential-technique/binary-search-framework/) chính là thứ ta muốn**.

Tới đây,思路 cốt lõi đề này就 nói xong, chủ yếu mấy bước:

1, Theo mảng trọng số `w` sinh mảng tổng tiền tố `preSum`.

2, Sinh một số ngẫu nhiên取值 trong `preSum`, dùng thuật toán tìm kiếm nhị phân tìm chỉ số phần tử nhỏ nhất lớn bằng số ngẫu nhiên này.

3, Cuối trừ một với chỉ số này (vì mảng tổng tiền tố có một lệch chỉ số), là có thể làm chỉ số mảng trọng số, tức đáp án cuối:

## Code解法

思路 trên hẳn không khó hiểu, nhưng lúc viết code坑可就多.

Phải biết đề liên quan khoảng đóng mở, lệch chỉ số và tìm kiếm nhị phân, cần bạn把控 chi tiết thuật toán非常精确, nếu không会 ra đủ loại bug khó排查.

Dưới đây抠 chi tiết, tiếp ví dụ trước:

![](https://labuladong.online/algo/images/random-weight/3.jpeg)

Ví dụ mảng `preSum` này, bạn thấy số ngẫu nhiên `target` nên取值 phạm vi nào? Khoảng đóng `[0, 7]` hay左闭右开 `[0, 7)`?

Đều không phải, nên trong khoảng đóng `[1, 7]` chọn, **vì 0 trong mảng tổng tiền tố本质上 là một占位符**,体会 kỹ một chút:

![](https://labuladong.online/algo/images/random-weight/6.jpeg)

Nên要 viết code vậy:

```java
int n = preSum.length;
// target 取值范围是闭区间 [1, preSum[n - 1]] -> Phạm vi取值 target là khoảng đóng [1, preSum[n - 1]]
int target = rand.nextInt(preSum[n - 1]) + 1;
```

Tiếp, trong `preSum` tìm chỉ số phần tử nhỏ nhất lớn bằng `target`, nên dùng tìm kiếm nhị phân品种 nào? Tìm biên trái hay biên phải?

Thực tế nên dùng tìm kiếm nhị phân tìm biên trái:

```java
// 搜索左侧边界的二分搜索 -> Tìm kiếm nhị phân biên trái
int left_bound(int[] nums, int target) {
    if (nums.length == 0) return -1;
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            right = mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else if (nums[mid] > target) {
            right = mid;
        }
    }
    return left;
}
```

Bài trước [chi tiết tìm kiếm nhị phân](https://labuladong.online/algo/essential-technique/binary-search-framework/)着重讲 trường hợp mảng tồn tại phần tử mục tiêu trùng, chưa讲 kỹ trường hợp phần tử mục tiêu không tồn tại, ở đây bổ sung một chút.

**Khi phần tử mục tiêu `target` không tồn tại trong mảng `nums`,返回值 của tìm kiếm nhị phân biên trái có thể解读 mấy loại sau**:

1, Giá trị trả về này là chỉ số phần tử nhỏ nhất lớn bằng `target` trong `nums`.

2, Giá trị trả về này là vị trí chỉ số `target` nên chèn trong `nums`.

3, Giá trị trả về này là số phần tử nhỏ hơn `target` trong `nums`.

Ví dụ trong mảng có thứ tự `nums = [2,3,5,7]` tìm `target = 4`, thuật toán nhị phân biên trái sẽ trả về 2, bạn带入 cách nói trên, đều đúng.

Nên ba解读 trên đều等价, có thể theo cảnh đề cụ thể linh hoạt dùng,显然 ở đây ta cần loại một.

Tóm lại, ta có thể viết ra code解法 cuối:

```java
class Solution {
    // 前缀和数组 -> Mảng tổng tiền tố
    private int[] preSum;
    private Random rand = new Random();
    
    public Solution(int[] w) {
        int n = w.length;
        // 构建前缀和数组，偏移一位留给 preSum[0] -> Dựng mảng tổng tiền tố, lệch một vị trí cho preSum[0]
        preSum = new int[n + 1];
        preSum[0] = 0;
        // preSum[i] = sum(w[0..i-1])
        for (int i = 1; i <= n; i++) {
            preSum[i] = preSum[i - 1] + w[i - 1];
        }
    }
    
    public int pickIndex() {
        int n = preSum.length;
        // Java 的 nextInt(n) 方法在 [0, n) 中生成一个随机整数 -> Method nextInt(n) của Java sinh một số nguyên ngẫu nhiên trong [0, n)
        // 再加一就是在闭区间 [1, preSum[n - 1]] 中随机选择一个数字 -> Cộng một nữa chính là chọn ngẫu nhiên một số trong khoảng đóng [1, preSum[n - 1]]
        int target = rand.nextInt(preSum[n - 1]) + 1;
        // 获取 target 在前缀和数组 preSum 中的索引 -> Lấy chỉ số target trong mảng tổng tiền tố preSum
        // 别忘了前缀和数组 preSum 和原始数组 w 有一位索引偏移 -> Đừng quên mảng tổng tiền tố preSum và mảng gốc w có một lệch chỉ số
        return left_bound(preSum, target) - 1;
    }

    // 搜索左侧边界的二分搜索 -> Tìm kiếm nhị phân biên trái
    private int left_bound(int[] nums, int target) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                right = mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else if (nums[mid] > target) {
                right = mid;
            }
        }
        return left;
    }
}
```
