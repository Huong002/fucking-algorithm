Bài trước [tổng hợp技巧 con trỏ đôi mảng](https://labuladong.online/algo/essential-technique/array-two-pointers-summary/)讲回文串 và vấn đề回文序列, trước ôn đơn giản.

**Tìm**回文串思想 cốt lõi là mở rộng từ中心 ra hai đầu:

```java
// 在 s 中寻找以 s[left] 和 s[right] 为中心的最长回文串 -> Tìm trong s串回文 dài nhất lấy s[left] và s[right] làm中心
String palindrome(String s, int left, int right) {
    // 防止索引越界 -> Tránh vượt biên chỉ số
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        // 双指针，向两边展开 -> Hai con trỏ, mở ra hai bên
        left--;
        right++;
    }
    // 返回以 s[left] 和 s[right] 为中心的最长回文串 -> Trả về串回文 dài nhất lấy s[left] và s[right] làm中心
    return s.substring(left + 1, right);
}
```

Vì độ dài回文串 có thể lẻ cũng có thể chẵn, dài lẻ chỉ tồn tại một điểm中心, còn dài chẵn tồn tại hai điểm中心, nên hàm trên cần truyền `l` và `r`.

Còn **判断** một chuỗi có phải回文串 không就 đơn giản nhiều, không cần xét chẵn lẻ, chỉ cần [技巧 hai con trỏ](https://labuladong.online/algo/essential-technique/array-two-pointers-summary/),逼近 từ hai đầu vào giữa là được:

```java
boolean isPalindrome(String s) {
    // 一左一右两个指针相向而行 -> Hai con trỏ trái phải đi ngược nhau
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

Code trên rất dễ hiểu吧, **vì回文串 đối xứng, nên đọc xuôi và đọc ngược hẳn giống nhau, đặc điểm này là mấu chốt giải vấn đề回文串**.

Dưới đây mở rộng trường hợp đơn giản nhất này, để giải: làm sao判断 một 「linked list đơn」 có phải回文.

## Một,判断 linked list đơn回文

Xem LeetCode 234 「linked list回文」:

<Problem slug="palindrome-linked-list" />

Chữ ký hàm như sau:

```java
boolean isPalindrome(ListNode head);
```

Mấu chốt đề này在于, linked list đơn không thể duyệt ngược, không thể dùng技巧 hai con trỏ.

Vậy cách đơn giản nhất chính là, đảo linked list gốc存 vào một linked list mới, rồi so hai linked list này có giống nhau không. Về cách đảo linked list, xem bài trước [đệ quy đảo một phần linked list](https://labuladong.online/algo/data-structure/reverse-linked-list-recursion/).

Tôi ở [tư duy framework học cấu trúc dữ liệu](https://labuladong.online/algo/essential-technique/algorithm-summary/) từng nói, linked list兼具 cấu trúc đệ quy, cấu trúc cây chẳng qua là衍生 của linked list. Vậy, **linked list其实 cũng có thể có duyệt tiền序 và hậu序,靠思路 duyệt hậu序 cây nhị phân, không cần显式 đảo linked list gốc cũng có thể duyệt ngược linked list**:

```java
// 二叉树遍历框架 -> Framework duyệt cây nhị phân
void traverse(TreeNode root) {
    // 前序遍历代码 -> Code duyệt tiền序
    traverse(root.left);
    // 中序遍历代码 -> Code duyệt trung序
    traverse(root.right);
    // 后序遍历代码 -> Code duyệt hậu序
}

// 递归遍历单链表 -> Duyệt đệ quy linked list đơn
void traverse(ListNode head) {
    // 前序遍历代码 -> Code duyệt tiền序
    traverse(head.next);
    // 后序遍历代码 -> Code duyệt hậu序
}
```

Framework này có ý nghĩa chỉ đạo gì? Nếu tôi muốn in xuôi giá trị `val` trong linked list, có thể viết code ở vị trí duyệt tiền序; ngược lại, nếu muốn duyệt ngược linked list, là có thể thao tác ở vị trí duyệt hậu序:

```java
// 倒序打印单链表中的元素值 -> In ngược giá trị phần tử trong linked list đơn
void traverse(ListNode head) {
    if (head == null) return;
    traverse(head.next);
    // 后序遍历代码 -> Code duyệt hậu序
    print(head.val);
}
```

Nói tới đây,其实 có thể sửa một chút, mô phỏng hai con trỏ implement chức năng判断回文:

```java
class Solution {
    // 从左向右移动的指针 -> Con trỏ di từ trái sang phải
    ListNode left;
    // 从右向左移动的指针 -> Con trỏ di từ phải sang trái
    ListNode right;

    // 记录链表是否为回文 -> Ghi linked list có phải回文 không
    boolean res = true;

    boolean isPalindrome(ListNode head) {
        left = head;
        traverse(head);
        return res;
    }

    void traverse(ListNode right) {
        if (right == null) {
            return;
        }

        // 利用递归，走到链表尾部 -> Lợi dụng đệ quy, đi tới đuôi linked list
        traverse(right.next);

        // 后序遍历位置，此时的 right 指针指向链表右侧尾部 -> Vị trí duyệt hậu序, con trỏ right lúc này trỏ đuôi phải linked list
        // 所以可以和 left 指针比较，判断是否是回文链表 -> Nên có thể so với con trỏ left,判断 có phải linked list回文 không
        if (left.val != right.val) {
            res = false;
        }
        left = left.next;
    }
}
```

Logic cốt lõi làm vậy là gì? **Thực tế chính là bỏ node linked list vào một stack, rồi lấy ra, lúc này thứ tự phần tử就是 ngược**, chỉ là ta lợi dụng堆栈 hàm đệ quy mà thôi.

Đương nhiên, dù造 một linked list đảo hay lợi dụng duyệt hậu序, thời gian và không gian thuật toán đều O(N). Dưới đây ta nghĩ xem, có thể không dùng không gian phụ, giải vấn đề này không?

## Hai, tối ưu độ phức tạp không gian

思路 tốt hơn là thế này:

**1, Trước qua con trỏ nhanh chậm trong [技巧 con trỏ đôi linked list](https://labuladong.online/algo/essential-technique/linked-list-skills-summary/) tìm điểm giữa linked list**:

```java
ListNode slow, fast;
slow = fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}
// slow 指针现在指向链表中点 -> Con trỏ slow giờ trỏ điểm giữa linked list
```

![](https://labuladong.online/algo/images/palindrome-list/1.jpg)



**2, Nếu con trỏ `fast` không trỏ `null`,说明 độ dài linked list lẻ, `slow` còn phải tiến thêm một bước**:

```java
if (fast != null)
    slow = slow.next;
```

![](https://labuladong.online/algo/images/palindrome-list/2.jpg)

**3, Đảo linked list sau bắt đầu từ `slow`, giờ là có thể bắt đầu so串回文**:

```java
ListNode left = head;
ListNode right = reverse(slow);

while (right != null) {
    if (left.val != right.val)
        return false;
    left = left.next;
    right = right.next;
}
return true;
```

![](https://labuladong.online/algo/images/palindrome-list/3.jpg)



Tới đây, gộp 3 đoạn code trên lại就 hiệu quả giải vấn đề này, trong đó hàm `reverse` xem [đảo linked list đơn](https://labuladong.online/algo/data-structure/reverse-linked-list-recursion/):

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        ListNode slow, fast;
        slow = fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        
        if (fast != null)
            slow = slow.next;
        
        ListNode left = head;
        ListNode right = reverse(slow);
        while (right != null) {
            if (left.val != right.val)
                return false;
            left = left.next;
            right = right.next;
        }
        
        return true;
    }

    ListNode reverse(ListNode head) {
        ListNode pre = null, cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = pre;
            pre = cur;
            cur = next;
        }
        return pre;
    }
}
```

## Ba, tổng kết

Trước, tìm回文串 là mở từ giữa ra hai đầu,判断回文串 là co từ hai đầu vào giữa. Với linked list đơn, không thể trực tiếp duyệt ngược, có thể造 một linked list đảo mới, có thể lợi dụng duyệt hậu序 linked list, cũng có thể dùng stack倒序 xử linked list đơn.

Cụ thể tới vấn đề判断 linked list回文, vì tính đặc殊回文, có thể không đảo完全 linked list, mà仅仅 đảo một phần linked list,将 độ phức tạp không gian xuống O(1).
