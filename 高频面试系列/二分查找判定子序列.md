Tìm kiếm nhị phân bản thân không khó hiểu, khó ở巧 vận dụng技巧 tìm kiếm nhị phân.

Với một vấn đề, bạn có thể đều rất khó nghĩ nó với tìm kiếm nhị phân liên quan, ví dụ bài trước [dãy tăng dài nhất](https://labuladong.online/algo/dynamic-programming/longest-increasing-subsequence/)就靠 một game bài衍生 ra解法 tìm kiếm nhị phân.

Hôm nay讲 tiếp một bài巧 dùng tìm kiếm nhị phân, LeetCode 392 「判断 dãy con」:

Hãy bạn判定 chuỗi `s` có phải dãy con của chuỗi `t` không (có thể giả定 `s` dài比较小, mà `t` dài非常大).

Lấy hai ví dụ:

```
s = "abc", t = "**a**h**b**gd**c**", return true.

s = "axc", t = "ahbgdc", return false.
```

Đề rất dễ hiểu, mà trông rất đơn giản, nhưng rất khó nghĩ vấn đề này với tìm kiếm nhị phân liên quan吧?

### Một, phân tích vấn đề

Trước, một解法 rất đơn giản thế này:

<!-- muliti_language -->
```java
boolean isSubsequence(String s, String t) {
    int i = 0, j = 0;
    while (i < s.length() && j < t.length()) {
        if (s.charAt(i) == t.charAt(j)) {
            i++;
        }
        j++;
    }
    return i == s.length();
}
```

<visual slug='is-subsequence'/>

思路 nó cũng非常 đơn giản, lợi dụng hai con trỏ `i, j` lần lượt trỏ `s, t`, vừa tiến vừa khớp dãy con:

![](https://labuladong.online/algo/images/子序列/1.gif)

Bạn có lẽ hỏi, đây chẳng phải解法 tối ưu sao, độ phức tạp thời gian chỉ cần O(N), N là độ dài `t`.

Đúng, nếu仅仅 là vấn đề này,解法 này就够 tốt, **nhưng vấn đề này còn có follow up**:

Nếu cho bạn một loạt chuỗi `s1,s2,...` và chuỗi `t`, bạn cần判定 mỗi串 `s` có phải dãy con của `t` không (có thể giả定 `s`较 ngắn, `t` rất dài).

<!-- muliti_language -->
```java
boolean[] isSubsequence(String[] sn, String t);
```

Bạn có lẽ hỏi, đây không phải rất đơn giản sao, vẫn logic vừa rồi, thêm vòng for chẳng phải được?

Được, nhưng解法 này xử mỗi `s` độ phức tạp thời gian vẫn O(N), còn nếu巧 vận dụng tìm kiếm nhị phân, có thể降低 độ phức tạp thời gian,大约 O(MlogN). Vì N相对 M大 rất nhiều, nên hiệu suất后者 cao hơn.

### Hai,思路 nhị phân

思路 nhị phân chủ yếu là tiền xử `t`, dùng một từ điển `index`将 vị trí chỉ số mỗi ký tự xuất hiện按 thứ tự lưu lại:

<!-- muliti_language -->
```java
int m = s.length(), n = t.length();
ArrayList<Integer>[] index = new ArrayList[256];
// 先记下 t 中每个字符出现的位置 -> Ghi trước vị trí mỗi ký tự trong t xuất hiện
for (int i = 0; i < n; i++) {
    char c = t.charAt(i);
    if (index[c] == null) 
        index[c] = new ArrayList<>();
    index[c].add(i);
}
```

Ví dụ với tình huống này, khớp "ab" xong, nên khớp "c":

![](https://labuladong.online/algo/images/子序列/1.jpg)

Theo解法 trước, ta cần `j` tuyến tính tiến quét ký tự "c", nhưng靠 thông tin ghi trong `index`, **có thể tìm nhị phân chỉ số lớn hơn j trong `index[c]`**, ở ví dụ图 trên, chính là trong `[0,2,6]` tìm chỉ số lớn hơn 4 đó:

![](https://labuladong.online/algo/images/子序列/3.jpg)

Như vậy là trực tiếp được chỉ số "c" tiếp. Giờ vấn đề chính là, dùng tìm kiếm nhị phân tính chỉ số恰好 lớn hơn 4 đó thế nào? Đáp án là, tìm kiếm nhị phân tìm biên trái là làm được.

### Ba, bàn lại tìm kiếm nhị phân

Ở bài trước [chi tiết tìm kiếm nhị phân](https://labuladong.online/algo/essential-technique/binary-search-framework/)中,讲 chi tiết cách viết đúng ba thuật toán tìm kiếm nhị phân. Tìm kiếm nhị phân trả về chỉ số giá trị mục tiêu `val`, với tìm kiếm nhị phân tìm **biên trái**, có một tính đặc殊:

**Khi `val` không tồn tại, chỉ số được恰好 là chỉ số phần tử nhỏ nhất lớn hơn `val`**.

Ý gì, chính là nói nếu trong mảng `[0,1,3,4]` tìm phần tử 2, thuật toán sẽ trả về chỉ số 2, chính là vị trí phần tử 3, phần tử 3 là phần tử nhỏ nhất lớn hơn 2 trong mảng. Nên ta có thể lợi dụng tìm nhị phân tránh quét tuyến tính.

<!-- muliti_language -->
```java
// 查找左侧边界的二分查找 -> Tìm kiếm nhị phân biên trái
int left_bound(ArrayList<Integer> arr, int target) {
    int left = 0, right = arr.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (target > arr.get(mid)) {
            left = mid + 1;
        } else {
            right = mid;
        } 
    }
    if (left == arr.size()) {
        return -1;
    }
    return left;
}
```

Trên chính là tìm kiếm nhị phân biên trái, lát会 dùng, chi tiết trong đó xem bài trước [chi tiết tìm kiếm nhị phân](https://labuladong.online/algo/essential-technique/binary-search-framework/), ở đây không赘述 nữa.

Ở đây lấy chuỗi đơn `s` làm ví dụ, với nhiều chuỗi `s`, có thể抽 phần tiền xử ra.

<!-- muliti_language -->
```java
boolean isSubsequence(String s, String t) {
    int m = s.length(), n = t.length();
    // 对 t 进行预处理 -> Tiền xử t
    ArrayList<Integer>[] index = new ArrayList[256];
    for (int i = 0; i < n; i++) {
        char c = t.charAt(i);
        if (index[c] == null) 
            index[c] = new ArrayList<>();
        index[c].add(i);
    }
    
    // 串 t 上的指针 -> Con trỏ trên串 t
    int j = 0;
    // 借助 index 查找 s[i] -> 靠 index tìm s[i]
    for (int i = 0; i < m; i++) {
        char c = s.charAt(i);
        // 整个 t 压根儿没有字符 c -> Cả t根本 không có ký tự c
        if (index[c] == null) return false;
        int pos = left_bound(index[c], j);
        // 二分搜索区间中没有找到字符 c -> Trong khoảng tìm nhị phân không tìm thấy ký tự c
        if (pos == -1) return false;
        // 向前移动指针 j -> Di con trỏ j về trước
        j = index[c].get(pos) + 1;
    }
    return true;
}
```

int numMatchingSubseq(String s, String[] words) {
    // 对 s 进行预处理 -> Tiền xử s
    // char -> 该 char 的索引列表 -> char -> list chỉ số của char đó
    ArrayList<Integer>[] index = new ArrayList[256];
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (index[c] == null) {
            index[c] = new ArrayList<>();
        }
        index[c].add(i);
    }
    
    int res = 0;
    for (String word : words) {
        // 字符串 word 上的指针 -> Con trỏ trên chuỗi word
        int i = 0;
        // 串 s 上的指针 -> Con trỏ trên串 s
        int j = 0;
        // 借助 index 查找 word 中每个字符的索引 -> 靠 index tìm chỉ số mỗi ký tự trong word
        for (; i < word.length(); i++) {
            char c = word.charAt(i);
            // 整个 s 压根儿没有字符 c -> Cả s根本 không có ký tự c
            if (index[c] == null) {
                break;
            }
            int pos = left_bound(index[c], j);
            // 二分搜索区间中没有找到字符 c -> Trong khoảng tìm nhị phân không tìm thấy ký tự c
            if (pos == -1) {
                break;
            }
            // 向前移动指针 j -> Di con trỏ j về trước
            j = index[c].get(pos) + 1;
        }
        // 如果 word 完成匹配，则是子序列 -> Nếu word khớp xong, thì là dãy con
        if (i == word.length()) {
            res++;
        }
    }
    
    return res;
}

### c++

**解法 một: duyệt (cũng có thể dùng hai con trỏ):**  

```C++
class Solution {
public:
    bool isSubsequence(string s, string t) {
        // 遍历s -> Duyệt s
        for(int i = 0; i < s.size(); i++) {
            // 找到s[i]字符在t中的位置 -> Tìm vị trí ký tự s[i] trong t
            size_t pos = t.find(s[i]);
            
            // 如果s[i]字符不在t中，返回false -> Nếu ký tự s[i] không trong t, trả về false
            if(pos == std::string::npos) return false;
            // 如果s[i]在t中，后面就只看pos以后的字串，防止重复查找 -> Nếu s[i] trong t, sau chỉ xem串 con sau pos, tránh tìm trùng
            else t = t.substr(pos + 1);
        }
        return true;
    }
};
```

**解法 hai: tìm kiếm nhị phân:**  
```C++
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int m = s.size(), n = t.size();
        // 对 t 进行预处理 -> Tiền xử t
        vector<int> index[256];
        for (int i = 0; i < n; i++) {
            char c = t[i];
            index[c].push_back(i);
        }
        // 串 t 上的指针 -> Con trỏ trên串 t
        int j = 0;
        // 借助 index 查找 s[i] -> 靠 index tìm s[i]
        for (int i = 0; i < m; i++) {
            char c = s[i];
            // 整个 t 压根儿没有字符 c -> Cả t根本 không có ký tự c
            if (index[c].empty()) return false;
            int pos = left_bound(index[c], j);
            // 二分搜索区间中没有找到字符 c -> Trong khoảng tìm nhị phân không tìm thấy ký tự c
            if (pos == index[c].size()) return false;
            // 向前移动指针 j -> Di con trỏ j về trước
            j = index[c][pos] + 1;
        }
        return true;
    }
    // 查找左侧边界的二分查找 -> Tìm kiếm nhị phân biên trái
    int left_bound(vector<int> arr, int tar) {
        int lo = 0, hi = arr.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (tar > arr[mid]) {
                lo = mid + 1;
            } else {
                hi = mid;
            } 
        }
        return lo;
    }
};
```



### javascript

Cách hai con trỏ quét một lần

```js
/**
 * @param {string} s
 * @param {string} t
 * @return {boolean}
 */
var isSubsequence = function (s, t) {
    let i = 0, j = 0;
    while (i < s.length && j < t.length) {
        if (s[i] === t[j]) i++;
        j++;
    }
    return i === s.length;
};
```



**Nâng cấp: cách nhị phân,应对 được trường hợp nhiều s**

```js
var isSubsequence = function (s, t) {
    let m = s.length, n = t.length;
    let index = new Array(256);
    // 先记下 t 中每个字符出现的位置 -> Ghi trước vị trí mỗi ký tự trong t xuất hiện
    for (let i = 0; i < n; i++) {
        let c = t[i];
        if (index[c] == null) {
            index[c] = [];
        }
        index[c].push(i)
    }

    // 串t上的指针 -> Con trỏ trên串 t
    let j = 0;
    // 借助index查找s[i] -> 靠 index tìm s[i]
    for (let i = 0; i < m; i++) {
        let c = s[i];
        // 整个t压根没有字符c -> Cả t根本 không có ký tự c
        if (index[c] == null) return false
        let pos = left_bound(index[c], j);
        // 二分搜索区间中没有找到字符c -> Trong khoảng tìm nhị phân không tìm thấy ký tự c
        if (pos == index[c].length) return false;

        // 向前移动指针j -> Di con trỏ j về trước
        j = index[c][pos] + 1;
    }
    return true;
};

var left_bound = function (arr, tar) {
    let lo = 0, hi = arr.length;
    while (lo < hi) {

        let mid = lo + Math.floor((hi - lo) / 2);
        if (tar > arr[mid]) {
            lo = mid + 1;
        } else {
            hi = mid;
        }
    }
    return lo;
}
```
