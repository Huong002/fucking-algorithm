## Lật toàn bộ单链表

Trong LeetCode/力扣, cấu trúc tổng quát của单链表 như sau:

```java
// Cấu trúc Node单链表
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}
```

Lật单链表 là một bài thuật toán比较cơ bản, bài 206 trên LeetCode「Lật linked list」chính là vấn đề này:

<Pronlem slug="reverse-linked-list" />

Dưới đây chúng ta thử dùng nhiều cách giải vấn đề này.

###解法lặp

Cách thường của bài này chính là解法lặp, qua thao tác mấy con trỏ,把hướng con trỏ của mỗi Node trong linked list lật, không có khó gì, chủ yếu là chi tiết thao tác con trỏ.

Ở đây给thẳng code, kết hợp chú thích và panel trực quan phải không khó hiểu:

```java
class Solution {
    // Lật单链表起点là head
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        // Vì cấu trúc单链表, ít nhất要用ba con trỏ mới hoàn thành lật lặp
        // cur là Node duyệt hiện tại, pre là Node前驱của cur, nxt là Node後繼của cur
        ListNode pre, cur, nxt;
        pre = null; cur = head; nxt = head.next;
        while (cur != null) {
            //逐Node lật
            cur.next = pre;
            // Cập nhật vị trí con trỏ
            pre = cur;
            cur = nxt;
            if (nxt != null) {
                nxt = nxt.next;
            }
        }
        // Trả về Node đầu后lật
        return pre;
    }
}
```

> Logic code thao tác单链表 trên không phức tạp, mà cũng không chỉ một cách viết đúng của tôi. Nhưng khi thao tác con trỏ, có vài tiểu xảo rất cơ bản, rất đơn giản, có thể khiến思路viết code của bạn rõ hơn:
>
> 1、Một khi xuất hiện thao tác kiểu `nxt.next`,就要phản xạ条件nghĩ,判断trước `nxt` có null không, nếu không dễ xuất hiện null pointer exception.
>
> 2、Chú ý điều kiện终止vòng lặp. Bạn要biết khi vòng lặp终止, vị trí các con trỏ, như vậy mới保trả về đáp án đúng. Nếu bạn thấy hơi phức tạp nghĩ không rõ, vậy动手vẽ một场景đơn giản nhất chạy thuật toán, ví dụ bài này có thể vẽ một单链表 chỉ hai Node `1->2`, rồi là có thể xác định sau khi vòng lặp终止vị trí các con trỏ.

###解法đệ quy

解法lặp trên thao tác con trỏ dù hơi繁琐, nhưng思路vẫn比较rõ. Nếu giờ bắt bạn dùng đệ quy để lật单链表, bạn có想法gì?

Với người mới có thể rất khó nghĩ, đây rất bình thường. Nếu bạn học tư duy thuật toán series cây nhị phân ở phần sau, quay đầu看lại bài này, mới có thể tự nghĩ ra thuật toán này.

Vì cấu trúc cây nhị phân本身chính là延伸của单链表, tương đương là链表nhị chạc嘛, nên tư duy đệ quy trên cây nhị phân,套lên单链表 là giống nhau.

**Mấu chốt đệ quy lật单链表 là, vấn đề本身tồn tại cấu trúc bài con**.

Ví dụ, giờ cho bạn nhập một单链表头là `1` là `1->2->3->4`, vậy nếu tôi bỏ qua头 `1` này, chỉ lấy ra链表con `2->3->4` này, nó cũng là单链表 đúng không?

Vậy hàm `reverseList` này của bạn, chỉ cần nhập một单链表, là có thể lật cho tôi đúng không? Vậy bạn có thể dùng hàm này lật链表con `2->3->4` này trước không, rồi nghĩ cách把 `1` nối vào cuối của `4->3->2`後lật, có phải就hoàn thành lật cả linked list?

```java
reverseList(1->2->3->4) = reverseList(2->3->4) -> 1
```


**Đây chính là思路「phân rã bài toán」, qua định nghĩa của hàm đệ quy,把bài gốc phân thành若干bài con quy mô nhỏ hơn, cấu trúc giống nhau, cuối cùng qua đáp án của bài con组装解của bài gốc**.

Trong tutorial sau sẽ có chương chuyên讲解và luyện tư duy này, ở đây không展开.

Xem trước cài đặt code đệ quy lật单链表:

```java
class Solution {
    // Định nghĩa: nhập một头单链表,把linked list này lật, trả về头mới
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode last = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return last;
    }
}
```

Thuật toán này thường拿来thể hiện巧妙và优美của đệ quy, dưới đây chúng ta giải thích chi tiết đoạn code này, cuối cùng给ra panel trực quan, bạn có thể tự动手tìm hiểu quá trình đệ quy.

Với thuật toán đệ quy思路「phân rã bài toán」, quan trọng nhất chính là明确định nghĩa của hàm đệ quy. Cụ thể, định nghĩa hàm `reverseList` của chúng ta như sau:

**Nhập một Node `head`,把linked list「起点là `head`」lật, và trả về头後lật**.

Hiểu định nghĩa của hàm后, xem lại vấn đề này. Ví dụ chúng ta muốn lật linked list này:

Vậy sau khi nhập `reverseList(head)`, sẽ đệ quy ở đây:

```java
ListNode last = reverseList(head.next);
```


Đừng nhảy vào đệ quy (đầu bạn能đè mấy stack?), mà要dựa vào định nghĩa hàm vừa rồi,来弄rõ đoạn code này sẽ sinh kết quả gì:

![](https://labuladong.online/algo/images/reverse-linked-list/3.jpg)

Giờ xem lại code dưới:

```java
head.next.next = head;
```

![](https://labuladong.online/algo/images/reverse-linked-list/4.jpg)

Tiếp theo:


Thần không thần kỳ, như vậy cả linked list就lật qua! Code đệ quy chính là gọn优雅vậy, nhưng trong đó có hai chỗ cần chú ý:

1、Hàm đệ quy要có base case, chính là câu này:

```java
if (head == null || head.next == null) {
    return head;
}
```

Ý là nếu linked list rỗng hoặc chỉ một Node, kết quả lật chính là nó, trả về thẳng là được.

2、Khi linked list đệ quy lật后,头mới là `last`, mà `head` trước đó thành Node cuối cùng, đừng quên末尾của linked list要指向null:

```java
head.next = null;
```

## Lật N Node đầu của linked list

Lần này chúng ta cài đặt một hàm thế này:

```java
// Lật n Node đầu của linked list (n <= độ dài linked list)
ListNode reverseN(ListNode head, int n)
```

Ví dụ với linked list ở hình dưới, chạy `reverseN(head, 3)`:

![](https://labuladong.online/algo/images/reverse-linked-list/6.jpg)






###解法lặp

解法lặp phải比较好viết, trên cơ sở `reverseList` cài đặt trước đó sửa chút là được:

```java
ListNode reverseN(ListNode head, int n) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode pre, cur, nxt;
    pre = null; cur = head; nxt = head.next;
    while (n > 0) {
        cur.next = pre;
        pre = cur;
        cur = nxt;
        if (nxt != null) {
            nxt = nxt.next;
        }
        n--;
    }
    // Lúc này cur là Node thứ n + 1, head là尾Node後lật
    head.next = cur;
    // Lúc này pre là头Node後lật
    return pre;
}
```

###解法đệ quy

思路đệ quy và đệ quy lật cả linked list gần giống, chỉ cần sửa chút là được:

```java
// Node後驅
ListNode successor = null;

// Lật n Node起点là head, trả về头mới
ListNode reverseN(ListNode head, int n) {
    if (n == 1) {
        // Ghi Node thứ n + 1
        successor = head.next;
        return head;
    }
    // Lấy head.next làm起点, cần lật n - 1 Node đầu
    ListNode last = reverseN(head.next, n - 1);

    head.next.next = head;
    // Để Node head後lật nối với Node phía sau
    head.next = successor;
    return last;
}
```

区别cụ thể:

1、base case thành `n == 1`, lật một phần tử, chính là nó, **đồng thời要ghi Node後驅**, tức要ghi Node thứ `n + 1`.

2、Vừa rồi chúng ta把 `head.next` đặt thẳng thành null, vì cả linked list lật后 `head` gốc thành Node cuối cùng của cả linked list. Nhưng giờ Node `head` sau khi đệ quy lật không一定là Node cuối cùng, nên要ghi後驅 `successor` (Node thứ `n + 1`),後lật把 `head` nối lên.

## Lật một phần của linked list

Chúng ta có thể tiến thêm, cho bạn một区间index, bắt bạn把phần tử trong区间này của单链表lật, phần khác không đổi.

Bài 92 trên LeetCode「Lật linked list II」chính là vấn đề này:

<Problem slug="reverse-linked-list-ii" />



Đề nhập区间index `[m, n]` (index bắt đầu từ 1),仅仅lật phần tử linked list trong区间, chữ ký hàm như sau:

```java
ListNode reverseBetween(ListNode head, int m, int n)
```

###解法lặp

思路thuần lặp比较trực tiếp, có thể tìm Node thứ `m - 1` trước, rồi复用hàm `reverseN` cài đặt trước đó là được:

```java
class Solution {
    public ListNode reverseBetween(ListNode head, int m, int n) {
        if (m == 1) {
            return reverseN(head, n);
        }
        // Tìm前驅của Node thứ m
        ListNode pre = head;
        for (int i = 1; i < m - 1; i++) {
            pre = pre.next;
        }
        // Bắt đầu lật từ Node thứ m
        pre.next = reverseN(pre.next, n - m + 1);
        return head;
    }

    ListNode reverseN(ListNode head, int n) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode pre, cur, nxt;
        pre = null; cur = head; nxt = head.next;
        while (n > 0) {
            cur.next = pre;
            pre = cur;
            cur = nxt;
            if (nxt != null) {
                nxt = nxt.next;
            }
            n--;
        }
        // Lúc này cur là Node thứ n + 1, head là尾Node後lật
        head.next = cur;
        // Lúc này pre là头Node後lật
        return pre;
    }
}
```

###解法đệ quy

解法thuần đệ quy, vẫn là tìm Node thứ `m - 1`, rồi复用hàm `reverseN` cài đặt trước đó là được.

Mấu chốt là, qua cách đệ quy tìm Node thứ `m - 1` thế nào?

Nếu chúng ta xem index của `head` là 1, vậy chúng ta muốn lật bắt đầu từ phần tử thứ `m` đúng không; nếu xem index của `head.next` là 1? Vậy tương đối với `head.next`,区间lật phải bắt đầu từ phần tử thứ `m - 1`; vậy với `head.next.next`?...

Đây thực ra chính là dùng cách đệ quy để lặp. Chúng ta có thể viết code thế này:

```java
class Solution {
    public ListNode reverseBetween(ListNode head, int m, int n) {
        // base case
        if (m == 1) {
            return reverseN(head, n);
        }
        // Tiến tới起点lật kích hoạt base case
        head.next = reverseBetween(head.next, m - 1, n - 1);
        return head;
    }

    // Node後驅
    ListNode successor = null;

    // Lật n Node起点là head, trả về头mới
    ListNode reverseN(ListNode head, int n) {
        if (n == 1) {
            // Ghi Node thứ n + 1
            successor = head.next;
            return head;
        }
        ListNode last = reverseN(head.next, n - 1);

        head.next.next = head;
        head.next = successor;
        return last;
    }
}
```

## Lật linked list theo nhóm K

Vấn đề này thường thấy trong面经, mà trên LeetCode độ khó là Hard, xem đề:

<Problem slug="reverse-nodes-in-k-group" />

Có lót層層trước đó, nó thực khó vậy sao? Thực ra chỉ cần bạn dùng tư duy「phân rã bài toán」, rồi复用thẳng hàm `reverseN` phía trước là được.






### Phân tích思路

Nghĩ kỹ có thể phát hiện **vấn đề này có tính đệ quy**.

Ví dụ chúng ta gọi `reverseKGroup(head, 2)` với linked list này, tức lật linked list theo nhóm 2 Node:

![](https://labuladong.online/algo/images/kgroup/1.jpg)

Nếu tôi设法lật 2 Node đầu, vậy những Node phía sau xử lý sao? Những Node phía sau này cũng là một linked list, mà quy mô (độ dài) nhỏ hơn linked list gốc này, đây就叫bài con quy mô nhỏ hơn, cấu trúc giống nhau.

Chúng ta có thể di con trỏ `head` gốc tới开头của đoạn linked list phía sau này, rồi tiếp tục đệ quy gọi `reverseKGroup(head, 2)`:

![](https://labuladong.online/algo/images/kgroup/2.jpg)

Phát hiện tính đệ quy, là có thể ra流程thuật toán大致:

**1、Lật `k` phần tử开头là `head` trước**. Ở đây có thể复用hàm `reverseN` cài đặt trước đó.

![](https://labuladong.online/algo/images/kgroup/3.jpg)

**2、Lấy phần tử thứ `k + 1` làm `head` đệ quy gọi hàm `reverseKGroup`**.

![](https://labuladong.online/algo/images/kgroup/4.jpg)

**3、Nối kết quả của hai quá trình trên lại**.

### Cài đặt code

Kết hợp讲解từng bước trên, code là có thể viết thẳng ra. Tôi ở đây dùng hàm `reverseN` dạng lặp, bạn muốn dùng dạng đệ quy cũng được:

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null) return null;
        //区间 [a, b) chứa k phần tử待lật
        ListNode a, b;
        a = b = head;
        for (int i = 0; i < k; i++) {
            // Không đủ k个, không cần lật nữa
            if (b == null) return head;
            b = b.next;
        }
        // Lật k phần tử đầu
        ListNode newHead = reverseN(a, k);
        // Lúc này b指向头待lật của nhóm tiếp theo
        // Đệ quy lật linked list sau đó và nối lại
        a.next = reverseKGroup(b, k);
        return newHead;
    }

    // Hàm lật N Node đầu cài đặt ở trên
    ListNode reverseN(ListNode head, int n) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode pre, cur, nxt;
        pre = null; cur = head; nxt = head.next;
        while (n > 0) {
            cur.next = pre;
            pre = cur;
            cur = nxt;
            if (nxt != null) {
                nxt = nxt.next;
            }
            n--;
        }
        head.next = cur;
        return pre;
    }
}
```
