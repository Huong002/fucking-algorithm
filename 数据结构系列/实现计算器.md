Chức năng máy tính chúng ta cuối cùng要cài đặt như sau:

1、Nhập một chuỗi, có thể chứa `+ - * /`, số, ngoặc và khoảng trắng, thuật toán của bạn trả về kết quả tính.

2、Phải符合quy tắc tính, ngoặc ưu tiên cao nhất, nhân chia trước cộng trừ sau.

3、Phép chia là chia nguyên, dù正âm đều取整về 0 (5/2=2, -5/2=-2).

4、Có thể giả định算式nhập肯定hợp lệ, và quá trình tính không xuất hiện tràn số nguyên, không xuất hiện tình huống意外chia cho 0.

Ví dụ nhập chuỗi sau, thuật toán sẽ trả về 9:

```java
  3 * (2 - 6 / (3 - 7))
= 3 * (2 - 6 / (-4))
= 3 * (2 - (-1))
= 9
```

Thấy đấy, đây đã rất gần máy tính dùng trong đời thực của chúng ta, dù trước đây肯定đều dùng máy tính, nhưng nếu nghĩ đơn giản về cài đặt thuật toán của nó, sẽ大惊失色:

1、Theo lẽ thường xử lý ngoặc, phải tính ngoặc trong cùng trước, rồi慢慢hóa giản ra ngoài. Quá trình này tay tính còn dễ sai, huống gì viết thành thuật toán!

2、Phải làm được nhân chia trước, cộng trừ sau, dạy trẻ con điểm này không算khó, nhưng dạy máy tính恐怕hơi khó.

3、Phải xử lý khoảng trắng. Vì美观, chúng ta quen打khoảng trắng giữa số và toán tử, nhưng trong tính toán phải nghĩ cách bỏ qua khoảng trắng này.

Tôi nhớ nhiều giáo trình cấu trúc dữ liệu đại học, khi讲stack, chắc đều lấy máy tính ví dụ, nhưng có một nói một,讲thực sự垃圾, không biết bao nhiêu nhà khoa học máy tính tương lai就被cấu trúc dữ liệu đơn giản này劝退.

Vậy bài này来聊làm sao cài đặt chức năng máy tính đầy đủ trên, **mấu chốt là層層拆解vấn đề,化整为零,逐个击破**, vài quy tắc thuật toán đơn giản là có thể xử lý tính toán cực phức tạp, tin rằng cách tư duy này giúp mọi người giải các vấn đề phức tạp.

Dưới đây来拆解, bắt đầu từ một vấn đề đơn giản nhất.

## Một, chuỗi chuyển số nguyên

Đúng, chính là một vấn đề đơn giản vậy, trước hết nói tôi, chuyển một số nguyên **dương** dạng chuỗi thành kiểu int thế nào?

```java
String s = "458";

int n = 0;
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
    n = 10 * n + (c - '0');
}
// n giờ就等于458
```

Vẫn rất đơn giản đúng không,套路cũ. Nhưng dù đơn giản vậy, vẫn có坑: **ngoặc của `(c - '0')` không được省略, nếu không có thể gây tràn số nguyên**.

Vì biến `c` là mã ASCII, nếu không加ngoặc sẽ cộng trước trừ sau, tưởng tượng `s` nếu gần INT_MAX, sẽ tràn. Nên dùng ngoặc đảm bảo trừ trước cộng sau mới được.

## Hai, xử lý cộng trừ

Giờ tiến thêm, **nếu算式nhập chỉ chứa cộng trừ, mà không tồn tại khoảng trắng**, bạn tính kết quả thế nào? Lấy算式chuỗi `1-12+3` ví dụ, nói một思路rất đơn giản:

1、Thêm cho số đầu một ký hiệu mặc định `+`, thành `+1-12+3`.

2、Ghép một toán tử và số thành một cặp, tức ba cặp `+1`, `-12`, `+3`, chuyển chúng thành số, rồi放vào một stack.

3、Cộng mọi số trong stack, chính là kết quả算式gốc.

Chúng ta xem thẳng code, kết hợp một hình là hiểu:

```java
int calculate(String s) {
    Stack<Integer> stk = new Stack<>();
    // Ghi lại số trong算式
    int num = 0;
    // Ghi lại ký hiệu trước num, khởi tạo là +
    char sign = '+';
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        // Nếu là số, đọc liên tục vào num
        if (Character.isDigit(c)) {
            num = 10 * num + (c - '0');
        }
        // Nếu không phải số, chính là gặp ký hiệu tiếp theo, hoặc là末尾của算式
        // Vậy số và ký hiệu trước đó就要存vào stack
        if (c == '+' || c == '-' || i == s.length() - 1) {
            switch (sign) {
                case '+':
                    stk.push(num); break;
                case '-':
                    stk.push(-num); break;
            }
            // Cập nhật ký hiệu thành ký hiệu hiện tại, số清零
            sign = c;
            num = 0;
        }
    }
    // Cộng mọi kết quả trong stack chính là đáp án
    int res = 0;
    while (!stk.isEmpty()) {
        res += stk.pop();
    }
    return res;
}
```

Tôi đoán chính là phần带câu `switch` ở giữa hơi khó hiểu, `i` chính là quét từ trái sang phải, `sign` và `num` theo sau nó. Khi `s[i]` gặp một toán tử, tình huống như sau:

![](https://labuladong.online/algo/images/calculator/1.jpg)

Cho nên, lúc này要dựa vào case khác nhau của `sign` chọn正âm của `nums`,存vào stack, rồi cập nhật `sign` và清零 `nums` ghi cặp符合và số tiếp theo.

Ngoài ra chú ý, không chỉ gặp ký hiệu mới kích hoạt入stack, khi `i` đi tới尽头của算式 (`i == s.size() - 1`), cũng phải đẩy số phía trước入stack, tiện tính kết quả cuối sau đó.

![](https://labuladong.online/algo/images/calculator/2.jpg)

Đến đây, thuật toán chỉ xử lý chuỗi cộng trừ gọn hoàn thành, hãy đảm bảo hiểu nội dung trên, nội dung sau就dựa trên khung này修 sửa là xong.

## Ba, xử lý nhân chia

Thực ra思路không khác gì chỉ xử lý cộng trừ, lấy chuỗi `2-3*4+5` ví dụ,思路cốt lõi vẫn là tách chuỗi thành组合ký hiệu và số.

Ví dụ trên có thể tách thành mấy cặp `+2`, `-3`, `*4`, `+5`, vừa rồi không phải chưa xử lý nhân chia sao, rất đơn giản, **phần khác都不用đổi**, thêm case tương ứng ở phần `switch` là được:

```java
int calculate(String s) {
    Stack<Integer> stk = new Stack<>();
    // Ghi lại số trong算式
    int num = 0;
    // Ghi lại ký hiệu trước num, khởi tạo là +
    char sign = '+';
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (Character.isDigit(c)) {
            num = 10 * num + (c - '0');
        }

        if (c == '+' || c == '-' || c == '/' || c == '*' || i == s.length() - 1) {
            int pre;
            switch (sign) {
                case '+':
                    stk.push(num); break;
                case '-':
                    stk.push(-num); break;
                // Chỉ cần lấy số trước đó làm tính tương ứng là được
                case '*':
                    pre = stk.pop();
                    stk.push(pre * num);
                    break;
                case '/':
                    pre = stk.pop();
                    stk.push(pre / num);
                    break;
            }
            // Cập nhật ký hiệu thành ký hiệu hiện tại, số清零
            sign = c;
            num = 0;
        }
    }
    // Cộng mọi kết quả trong stack chính là đáp án
    int res = 0;
    while (!stk.isEmpty()) {
        res += stk.pop();
    }
    return res;
}
```

![](https://labuladong.online/algo/images/calculator/3.jpg)



**Nhân chia ưu tiên hơn cộng trừ thể hiện ở, nhân chia có thể kết hợp với số đỉnh stack, mà cộng trừ chỉ放入mình vào stack**.

Giờ chúng ta nghĩ xem xử lý ký tự khoảng trắng có thể xuất hiện trong chuỗi thế nào. Thực ra theo code hiện tại, chúng ta căn bản不用xử lý đặc biệt ký tự khoảng trắng, bạn chú ý điều kiện if, khi ký tự `c` là khoảng trắng, không làm xử lý gì với nó, bỏ qua thẳng.

Tốt rồi, thuật toán giờ đã có thể tính cộng trừ nhân chia theo đúng法则, và tự động bỏ ký tự khoảng trắng, còn lại là làm sao để thuật toán nhận đúng ngoặc.

## Bốn, xử lý ngoặc

Xử lý ngoặc trong算式nhìn phải khó nhất, nhưng thực không khó như nhìn. Chúng ta sửa chút code trên trước:

```java
int calculate(String s) {
    return _calculate(s, 0, s.length() - 1);
}

// Định nghĩa: trả về kết quả tính của biểu thức trong s[start..end]
int _calculate(String s, int start, int end) {
    // Cần chuyển chuỗi thành hàng đợi hai đầu tiện thao tác
    Stack<Integer> stk = new Stack<>();
    // Ghi lại số trong算式
    int num = 0;
    // Ghi lại ký hiệu trước num, khởi tạo là +
    char sign = '+';
    for (int i = start; i <= end; i++) {
        char c = s.charAt(i);
        if (Character.isDigit(c)) {
            num = 10 * num + (c - '0');
        }

        if (c == '+' || c == '-' || c == '/' || c == '*' || i == s.length() - 1) {
            int pre;
            switch (sign) {
                case '+':
                    stk.push(num);
                    break;
                case '-':
                    stk.push(-num);
                    break;
                // Chỉ cần lấy số trước đó làm tính tương ứng là được
                case '*':
                    pre = stk.pop();
                    stk.push(pre * num);
                    break;
                case '/':
                    pre = stk.pop();
                    stk.push(pre / num);
                    break;
            }
            // Cập nhật ký hiệu thành ký hiệu hiện tại, số清零
            sign = c;
            num = 0;
        }
    }
    // Cộng mọi kết quả trong stack chính là đáp án
    int res = 0;
    while (!stk.isEmpty()) {
        res += stk.pop();
    }
    return res;
}
```

Ở đây chúng ta định nghĩa một hàm mới `_calculate`, nó nhận ba tham số, lần lượt là chuỗi `s`, và biên trái/phải `start` và `end` của chuỗi. Như vậy chúng ta có thể tính giá trị của子biểu thức bất kỳ trong `s`.

Vậy, tại sao nói xử lý ngoặc không khó như nhìn? **Vì ngoặc có tính đệ quy**. Lấy chuỗi `3*(4-5/2)-6` ví dụ:

```java
calculate(3 * (4 - 5/2) - 6)
= 3 * calculate(4 - 5/2) - 6
= 3 * 2 - 6
= 0
```

Có thể脑补, dù bao nhiêu tầng ngoặc lồng nhau, qua hàm `_calculate` đệ quy gọi mình, đều có thể tính算式trong ngoặc ra kết quả. **Nói cách khác,算式ngoặc chứa, chúng ta xem thẳng thành một số là được**.

Vậy giờ vấn đề là, nếu tôi gặp một ngoặc trái `(`, làm sao biết ngoặc phải `)` tương ứng ở đâu? Lại要用stack, chúng ta có thể预tính với `s`, tìm trước vị trí ngoặc phải tương ứng mỗi ngoặc trái.

Xem cụ thể code, dựa trên hàm `_calculate` trên, thêm ít logic:

```java
class Solution {
    public int calculate(String s) {
        // key là index ngoặc trái, value là index ngoặc phải tương ứng
        Map<Integer, Integer> rightIndex = new HashMap<>();
        // Lợi dụng cấu trúc stack để tìm ngoặc tương ứng
        Stack<Integer> stack = new Stack<>();
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else if (s.charAt(i) == ')') {
                rightIndex.put(stack.pop(), i);
            }
        }
        return _calculate(s, 0, s.length() - 1, rightIndex);
    }

    // Định nghĩa: trả về kết quả tính của biểu thức trong s[start..end]
    private int _calculate(String s, int start, int end, Map<Integer, Integer> rightIndex) {
        // Cần chuyển chuỗi thành hàng đợi hai đầu tiện thao tác
        Stack<Integer> stk = new Stack<>();
        // Ghi lại số trong算式
        int num = 0;
        // Ghi lại ký hiệu trước num, khởi tạo là +
        char sign = '+';
        for (int i = start; i <= end; i++) {
            char c = s.charAt(i);
            if (Character.isDigit(c)) {
                num = 10 * num + (c - '0');
            }
            if (c == '(') {
                // Đệ quy tính biểu thức trong ngoặc
                num = _calculate(s, i + 1, rightIndex.get(i) - 1, rightIndex);
                i = rightIndex.get(i);
            }
            if (c == '+' || c == '-' || c == '*' || c == '/' || i == end) {
                int pre;
                switch (sign) {
                    case '+':
                        stk.push(num);
                        break;
                    case '-':
                        stk.push(-num);
                        break;
                    // Chỉ cần lấy số trước đó làm tính tương ứng là được
                    case '*':
                        pre = stk.pop();
                        stk.push(pre * num);
                        break;
                    case '/':
                        pre = stk.pop();
                        stk.push(pre / num);
                        break;
                }
                // Cập nhật ký hiệu thành ký hiệu hiện tại, số清零
                sign = c;
                num = 0;
            }
        }
        // Cộng mọi kết quả trong stack chính là đáp án
        int res = 0;
        while (!stk.isEmpty()) {
            res += stk.pop();
        }
        return res;
    }
}
```

## Năm, tổng kết cuối

Bài này mượn vấn đề cài đặt máy tính, chủ yếu muốn表达một思路xử lý vấn đề phức tạp.

Chúng ta trước hết từ vấn đề đơn giản chuyển số từ chuỗi bắt đầu, rồi xử lý算式chỉ chứa cộng trừ, rồi xử lý算式chứa bốn phép cộng trừ nhân chia, rồi xử lý ký tự khoảng trắng, rồi xử lý算式chứa ngoặc.

Thấy được, với vài vấn đề比较khó,解法của nó không phải一蹴而就, mà là步步推进ốc tăng dần. Nếu ban đầu cho bạn đề gốc, bạn không biết làm, thậm chí看不懂đáp án,都很正常, mấu chốt là chúng ta tự简化vấn đề thế nào, 以退为进thế nào.

Hiểu rõ nguyên lý thuật toán máy tính后, **code máy tính toàn năng cài đặt cuối cùng này có thể lưu lại**, vài bài thuật toán khác có thể yêu cầu bạn tính giá trị biểu thức, đến lúc đó có thể套lớp này ra dùng thẳng, không cần tự viết từ đầu.
