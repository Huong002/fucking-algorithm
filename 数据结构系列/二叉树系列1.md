## Bài một, lật cây nhị phân

Chúng ta bắt đầu từ bài đơn giản, xem bài 226 trên LeetCode「Lật cây nhị phân」, nhập Node gốc `root` của một cây nhị phân, bắt bạn把cả cây镜像lật, ví dụ cây nhị phân nhập như sau:

```
     4
   /   \
  2     7
 / \   / \
1   3 6   9
```

Thuật toán lật cây nhị phân tại chỗ, khiến cây gốc `root` thành:

```
     4
   /   \
  7     2
 / \   / \
9   6 3   1
```

Không khó phát hiện, chỉ cần把Node trái/phải của mỗi Node trên cây nhị phân hoán đổi, kết quả cuối chính là cây nhị phân lật hoàn toàn.

Vậy giờ bắt đầu默念tổng纲giải cây nhị phân:

**1、Bài này có thể dùng mô thức tư duy「duyệt」giải không**?

Được, tôi viết một hàm `traverse` duyệt mỗi Node, để mỗi Node颠倒Node trái/phải là được.

抽riêng một Node, cần nó làm gì? Để nó hoán đổi Node trái/phải của mình.

Cần làm lúc nào?似乎vị trí tiền/trung/hậu序 đều được.

Tổng hợp, có thể viết code解法như sau:

```java
class Solution {
    // Hàm chính
    public TreeNode invertTree(TreeNode root) {
        // Duyệt cây nhị phân, hoán đổi Node con mỗi Node
        traverse(root);
        return root;
    }

    // Hàm duyệt cây nhị phân
    void traverse(TreeNode root) {
        if (root == null) {
            return;
        }

        // *** Vị trí tiền序 ***
        // Việc mỗi Node cần làm chính là hoán đổi Node trái/phải của nó
        TreeNode tmp = root.left;
        root.left = root.right;
        root.right = tmp;

        // Khung duyệt,去duyệt Node của cây con trái/phải
        traverse(root.left);
        traverse(root.right);
    }
}
```

Bạn chuyển code vị trí tiền序tới vị trí hậu序 cũng được, nhưng chuyển thẳng tới vị trí trung序 thì không được, cần sửa chút, cái này phải rất dễ看出, tôi就不nói.

Theo lý, bài này đã giải xong, nhưng để so sánh, chúng ta tiếp tục nghĩ xuống.

**2、Bài này có thể dùng mô thức tư duy「phân rã bài toán」giải không**?

Chúng ta thử赋định nghĩa cho hàm `invertTree`:

```java
// Định nghĩa: lật cây nhị phân gốc root này, trả về Node gốc của cây nhị phân lật后
TreeNode invertTree(TreeNode root);
```

Rồi nghĩ, với một Node cây nhị phân `x` nào đó chạy `invertTree(x)`, bạn能lợi dụng định nghĩa của hàm đệ quy này làm gì?

Tôi có thể dùng `invertTree(x.left)` lật cây con trái của `x` trước, rồi dùng `invertTree(x.right)` lật cây con phải của `x`, cuối cùng hoán đổi cây con trái/phải của `x`,恰好hoàn thành lật cả cây nhị phân gốc `x`, tức hoàn thành định nghĩa của `invertTree(x)`.

Viết thẳng code解法:

```java
class Solution {
    // Định nghĩa: lật cây nhị phân gốc root này, trả về Node gốc của cây nhị phân lật后
    public TreeNode invertTree(TreeNode root) {
        if (root == null) {
            return null;
        }
        // Lợi dụng định nghĩa hàm, lật cây con trái/phải trước
        TreeNode left = invertTree(root.left);
        TreeNode right = invertTree(root.right);

        // Rồi hoán đổi Node con trái/phải
        root.left = right;
        root.right = left;

        // Tự洽với logic định nghĩa: cây nhị phân gốc root đã被lật, trả về root
        return root;
    }
}
```

## Bài hai, điền con trỏ phía右của Node

Đây là bài 116 trên LeetCode「Điền con trỏ phía右của mỗi Node cây nhị phân」, xem đề:

<Problem slug="populating-next-right-pointers-in-each-node" />

```java
// Chữ ký hàm
Node connect(Node root);
```

Ý đề chính là把mỗi tầng Node của cây nhị phân đều dùng con trỏ `next` nối lại:

![](https://labuladong.online/algo/images/binary-tree-i/1.png)

Mà đề nói, nhập là một「cây nhị phân hoàn hảo」, hình tượng cả cây nhị phân là một tam giác正, trừ Node最右con trỏ `next` sẽ指向 `null`, phía右của Node khác肯定có Node kề.

Bài này làm sao?来默念tổng纲giải cây nhị phân:

**1、Bài này có thể dùng mô thức tư duy「duyệt」giải không**?

Rất hiển nhiên,肯定được.

Việc mỗi Node要làm cũng rất đơn giản,把con trỏ `next` của mình指向Node phía右là được.

Có thể bạn sẽ bắt chước bài trước, viết thẳng code sau:

```java
// Hàm duyệt cây nhị phân
void traverse(Node root) {
    if (root == null || root.left == null) {
        return;
    }
    //指向con trỏ next của Node con trái sang Node con phải
    root.left.next = root.right;

    traverse(root.left);
    traverse(root.right);
}
```

Nhưng, đoạn code này thực có vấn đề lớn, vì nó chỉ穿được hai Node cùng Node cha, xem lại hình này:

![](https://labuladong.online/algo/images/binary-tree-i/1.png)

Node 5 và Node 6 không thuộc cùng Node cha, vậy按logic của đoạn code này, nó俩就không cách nào被穿lại, đây không符合ý đề, nhưng vấn đề ở đâu?

**Hàm `traverse` truyền thống là duyệt mọi Node của cây nhị phân, nhưng giờ chúng ta muốn duyệt thực ra là「khe hở」giữa hai Node kề**.

Nên chúng ta có thể trừu tượng trên cơ sở cây nhị phân, bạn xem mỗi ô vuông trong hình thành một Node:

![](https://labuladong.online/algo/images/binary-tree-i/3.png)

**Như vậy, một cây nhị phân被trừu tượng thành một cây tam chạc, mỗi Node trên cây tam chạc chính là hai Node kề của cây nhị phân gốc**.

Giờ, chúng ta chỉ cần cài đặt một hàm `traverse` để duyệt cây tam chạc này, việc mỗi「Node cây tam chạc」cần làm chính là穿hai Node cây nhị phân bên trong mình lại:

```java
class Solution {
    // Hàm chính
    public Node connect(Node root) {
        if (root == null) return null;
        // Duyệt「cây tam chạc」, nối Node kề
        traverse(root.left, root.right);
        return root;
    }

    // Khung duyệt cây tam chạc
    void traverse(Node node1, Node node2) {
        if (node1 == null || node2 == null) {
            return;
        }
        // *** Vị trí tiền序 ***
        //穿hai Node truyền vào lại
        node1.next = node2;
        
        // Nối hai Node con của cùng Node cha
        traverse(node1.left, node1.right);
        traverse(node2.left, node2.right);
        // Nối hai Node con跨Node cha
        traverse(node1.right, node2.left);
    }
}
```

Như vậy, hàm `traverse` duyệt cả「cây tam chạc」,把mọi Node cây nhị phân kề nhau đều nối lại, cũng tránh vấn đề chúng ta xuất hiện trước đó,把bài này giải hoàn hảo.

**2、Bài này có thể dùng mô thức tư duy「phân rã bài toán」giải không**?

Ừm,似乎không có思路特别tốt, nên bài này không cách nào dùng tư duy「phân rã bài toán」để giải.

## Bài ba, trải cây nhị phân thành linked list

Đây là bài 114 trên LeetCode「Trải cây nhị phân thành linked list」, xem đề:

<Problem slug="flatten-binary-tree-to-linked-list" />

```java
// Chữ ký hàm như sau
void flatten(TreeNode root);
```

**1、Bài này có thể dùng mô thức tư duy「duyệt」giải không**?

Nhìn乍cảm giác được: duyệt tiền序cả cây, vừa duyệt vừa dựng một「linked list」là được:

```java
// Node đầu ảo, dummy.right chính là kết quả
TreeNode dummy = new TreeNode(-1);
// Con trỏ dùng dựng linked list
TreeNode p = dummy;

void traverse(TreeNode root) {
    if (root == null) {
        return;
    }
    // Vị trí tiền序
    p.right = new TreeNode(root.val);
    p = p.right;

    traverse(root.left);
    traverse(root.right);
}
```

Nhưng chú ý chữ ký của hàm `flatten`, kiểu trả về là `void`, tức đề hy vọng chúng ta拉 phẳngcây nhị phân tại chỗ thành linked list.

Như vậy, không cách nào qua duyệt cây nhị phân đơn giản để giải bài này.

**2、Bài này có thể dùng mô thức tư duy「phân rã bài toán」giải không**?

Chúng ta thử给ra định nghĩa của hàm `flatten`:

```java
// Định nghĩa: nhập Node root, rồi cây nhị phân gốc root sẽ被拉 phẳngthành một linked list
void flatten(TreeNode root);
```

Có định nghĩa hàm này,按yêu cầu đề把một cây拉 phẳngthành một linked list thế nào?

Với một Node `x`, có thể chạy流程sau:

1、Dùng `flatten(x.left)` và `flatten(x.right)`拉 phẳngcây con trái/phải của `x` trước.

2、Nối cây con phải của `x` xuống dưới cây con trái, rồi把cả cây con trái làm cây con phải.

![](https://labuladong.online/algo/images/binary-tree-i/2.jpeg)

Như vậy, cả cây nhị phân gốc `x`就被拉 phẳng,恰好hoàn thành định nghĩa của `flatten(x)`.

Xem thẳng cài đặt code:

```java
class Solution {
    // Định nghĩa:拉 phẳngcây gốc root thành linked list
    public void flatten(TreeNode root) {
        // base case
        if (root == null) return;
        
        // Lợi dụng định nghĩa,把cây con trái/phải拉 phẳng
        flatten(root.left);
        flatten(root.right);

        // *** Vị trí duyệt hậu序 ***
        // 1、Cây con trái/phải đã被拉 phẳngthành một linked list
        TreeNode left = root.left;
        TreeNode right = root.right;
        
        // 2、Lấy cây con trái làm cây con phải
        root.left = null;
        root.right = left;

        // 3、Nối cây con phải gốc vào末端của cây con phải hiện tại
        TreeNode p = root;
        while (p.right != null) {
            p = p.right;
        }
        p.right = right;
    }
}
```
