## Dựng cây nhị phân lớn nhất

Trước một bài đơn giản, đây là bài 654 trên LeetCode「Cây nhị phân lớn nhất」, đề như sau:

<Problem slug="maximum-binary-tree" />

```java
// Chữ ký hàm như sau
TreeNode constructMaximumBinaryTree(int[] nums);
```

Mỗi Node cây nhị phân đều có thể coi là Node gốc của một cây con, với Node gốc, đầu tiên要làm dĩ nhiên là把想办法把mình dựng ra trước, rồi想办法dựng cây con trái/phải của mình.

Nên, chúng ta要duyệt mảng把tìm giá trị lớn nhất `maxVal`, nhờ đó把Node gốc `root` làm ra, rồi với mảng bên trái `maxVal` và mảng bên右đệ quy dựng, làm cây con trái/phải của `root`.

按ví dụ đề cho, mảng nhập là `[3,2,1,6,0,5]`, với Node gốc của cả cây mà nói, thực ra đang làm việc này:

```java
TreeNode constructMaximumBinaryTree([3,2,1,6,0,5]) {
    // Tìm giá trị lớn nhất trong mảng
    TreeNode root = new TreeNode(6);
    // Đệ quy gọi dựng cây con trái/phải
    root.left = constructMaximumBinaryTree([3,2,1]);
    root.right = constructMaximumBinaryTree([0,5]);
    return root;
}

// Giá trị lớn nhất trong nums hiện tại chính là Node gốc, rồi dựa vào index đệ quy gọi mảng trái/phải dựng cây con trái/phải là được
// Chi tiết hơn, chính là伪码sau
TreeNode constructMaximumBinaryTree(int[] nums) {
    if (nums is empty) return null;
    // Tìm giá trị lớn nhất trong mảng
    int maxVal = Integer.MIN_VALUE;
    int index = 0;
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] > maxVal) {
            maxVal = nums[i];
            index = i;
        }
    }

    TreeNode root = new TreeNode(maxVal);
    // Đệ quy gọi dựng cây con trái/phải
    root.left = constructMaximumBinaryTree(nums[0..index-1]);
    root.right = constructMaximumBinaryTree(nums[index+1..nums.length-1]);
    return root;
}
```

**Giá trị lớn nhất trong `nums` hiện tại chính là Node gốc, rồi dựa vào index đệ quy gọi mảng trái/phải dựng cây con trái/phải là được**.

Rõ思路, chúng ta có thể viết lại một hàm phụ `build`,来khống chế index của `nums`:

```java
class Solution {

    public TreeNode constructMaximumBinaryTree(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    // Định nghĩa:把nums[lo..hi] dựng thành cây符合điều kiện, trả về Node gốc
    TreeNode build(int[] nums, int lo, int hi) {
        // base case
        if (lo > hi) {
            return null;
        }

        // Tìm giá trị lớn nhất trong mảng và index tương ứng
        int index = -1, maxVal = Integer.MIN_VALUE;
        for (int i = lo; i <= hi; i++) {
            if (maxVal < nums[i]) {
                index = i;
                maxVal = nums[i];
            }
        }

        // Dựng Node gốc ra trước
        TreeNode root = new TreeNode(maxVal);
        // Đệ quy gọi dựng cây con trái/phải
        root.left = build(nums, lo, index - 1);
        root.right = build(nums, index + 1, hi);
        
        return root;
    }
}
```

## Dựng cây nhị phân qua kết quả duyệt tiền序và trung序

Bài 105 trên LeetCode「Dựng cây nhị phân từ duyệt tiền序và trung序」chính là bài kinh điển này, phỏng vấn笔试thường考:

<Problem slug="construct-binary-tree-from-preorder-and-inorder-traversal" />

```java
// Chữ ký hàm như sau
TreeNode buildTree(int[] preorder, int[] inorder);
```

废话不多说, nghĩ thẳng思路, trước hết nghĩ, Node gốc phải làm gì.

**类似bài trước, chúng ta肯定要想办法xác định giá trị Node gốc,把Node gốc làm ra, rồi đệ quy dựng cây con trái/phải là được**.

Chúng ta ôn lại trước, kết quả duyệt tiền序và trung序 có đặc điểm gì?

```java
void traverse(TreeNode root) {
    // Duyệt tiền序
    preorder.add(root.val);
    traverse(root.left);
    traverse(root.right);
}

void traverse(TreeNode root) {
    traverse(root.left);
    // Duyệt trung序
    inorder.add(root.val);
    traverse(root.right);
}
```

Bài trước [Cây nhị phân就mấy khung đó](https://labuladong.online/algo/data-structure/flatten-nested-list-iterator/) viết, khác biệt thứ tự duyệt này, khiến phân bố phần tử trong mảng `preorder` và `inorder` có đặc điểm sau:

![](https://labuladong.online/algo/images/binary-tree-ii/1.jpeg)

Tìm Node gốc rất đơn giản, giá trị đầu của duyệt tiền序 `preorder[0]` chính là giá trị Node gốc.

Mấu chốt là qua giá trị Node gốc, chia mảng `preorder` và `inorder` thành hai半, dựng cây con trái/phải của Node gốc thế nào?

Nói cách khác, với phần `?` trong code sau phải điền gì:

```java
TreeNode buildTree(int[] preorder, int[] inorder) {
    // Theo định nghĩa hàm, dùng preorder và inorder dựng cây nhị phân
    return build(preorder, 0, preorder.length - 1,
                inorder, 0, inorder.length - 1);
}

// Định nghĩa của hàm build:
// Nếu mảng duyệt tiền序là preorder[preStart..preEnd],
// Mảng duyệt trung序là inorder[inStart..inEnd],
// Dựng cây nhị phân, trả về Node gốc của cây này
TreeNode build(int[] preorder, int preStart, int preEnd, 
            int[] inorder, int inStart, int inEnd) {
    // Giá trị Node root tương ứng chính là phần tử đầu của mảng duyệt tiền序
    int rootVal = preorder[preStart];
    // Index của rootVal trong mảng duyệt trung序
    int index = 0;
    for (int i = inStart; i <= inEnd; i++) {
        if (inorder[i] == rootVal) {
            index = i;
            break;
        }
    }

    TreeNode root = new TreeNode(rootVal);
    // Đệ quy dựng cây con trái/phải
    root.left = build(preorder, ?, ?,
                    inorder, ?, ?);

    root.right = build(preorder, ?, ?,
                    inorder, ?, ?);
    return root;
}
```

Với biến `rootVal` và `index` trong code, chính là tình huống hình dưới:

![](https://labuladong.online/algo/images/binary-tree-ii/2.jpeg)

Ngoài ra, cũng có độc giả chú ý, qua vòng for duyệt xác định `index` hiệu suất không算cao, có thể tối ưu thêm.

Vì đề nói giá trị Node cây nhị phân không tồn tại trùng, nên có thể dùng một HashMap lưu map từ phần tử tới index, như vậy là có thể tra thẳng `index` tương ứng `rootVal` qua HashMap:

Giờ chúng ta xem hình làm bài điền, mấy dấu hỏi dưới phải điền gì:

```java
root.left = build(preorder, ?, ?,
                  inorder, ?, ?);

root.right = build(preorder, ?, ?,
                   inorder, ?, ?);
```

Với index bắt đầu và kết thúc của mảng `inorder` tương ứng cây con trái/phải比较dễ xác định:

![](https://labuladong.online/algo/images/binary-tree-ii/3.jpeg)

```java
root.left = build(preorder, ?, ?,
                  inorder, inStart, index - 1);

root.right = build(preorder, ?, ?,
                   inorder, index + 1, inEnd);
```

Với mảng `preorder`? Xác định index bắt đầu và kết thúc tương ứng mảng trái/phải thế nào?

Cái này có thể qua số Node của cây con trái推ra, giả sử số Node của cây con trái là `leftSize`, vậy tình huống index trên mảng `preorder` như sau:

![](https://labuladong.online/algo/images/binary-tree-ii/4.jpeg)

Nhìn hình này là có thể viết index tương ứng `preorder` vào:

```java
int leftSize = index - inStart;

root.left = build(preorder, preStart + 1, preStart + leftSize,
                  inorder, inStart, index - 1);

root.right = build(preorder, preStart + leftSize + 1, preEnd,
                   inorder, index + 1, inEnd);
```

Đến đây,思路thuật toán tổng thể hoàn thành, chúng ta补thêm base case là có thể viết code解法:

```java
class Solution {
    // Lưu map từ giá trị tới index trong inorder
    HashMap<Integer, Integer> valToIndex = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        for (int i = 0; i < inorder.length; i++) {
            valToIndex.put(inorder[i], i);
        }
        return build(preorder, 0, preorder.length - 1,
                    inorder, 0, inorder.length - 1);
    }

    // Định nghĩa của hàm build:
    // Nếu mảng duyệt tiền序là preorder[preStart..preEnd],
    // Mảng duyệt trung序là inorder[inStart..inEnd],
    // Dựng cây nhị phân, trả về Node gốc của cây này
    TreeNode build(int[] preorder, int preStart, int preEnd, 
               int[] inorder, int inStart, int inEnd) {

        if (preStart > preEnd) {
            return null;
        }

        // Giá trị Node root tương ứng chính là phần tử đầu của mảng duyệt tiền序
        int rootVal = preorder[preStart];
        // Index của rootVal trong mảng duyệt trung序
        int index = valToIndex.get(rootVal);

        int leftSize = index - inStart;

        // Dựng Node gốc hiện tại ra trước
        TreeNode root = new TreeNode(rootVal);
        // Đệ quy dựng cây con trái/phải
        root.left = build(preorder, preStart + 1, preStart + leftSize,
                        inorder, inStart, index - 1);

        root.right = build(preorder, preStart + leftSize + 1, preEnd,
                        inorder, index + 1, inEnd);
        return root;
    }
}
```

Hàm chính của chúng ta chỉ cần gọi hàm `buildTree` là được, bạn nhìn hàm nhiều tham số vậy,解法nhiều code vậy,似乎比bài trên讲khó nhiều, khiến người望而生畏, thực tế呢, những tham số này chẳng qua khống chế vị trí bắt đầu/kết thúc mảng, vẽ hình là giải được.

## Dựng cây nhị phân qua kết quả duyệt hậu序và trung序

类似bài trước, lần này chúng ta lợi dụng mảng kết quả duyệt **hậu序** và **trung序** để还原cây nhị phân, đây là bài 106 trên LeetCode「Dựng cây nhị phân từ duyệt hậu序và trung序」:

<Problem slug="construct-binary-tree-from-inorder-and-postorder-traversal" />

```java
// Chữ ký hàm như sau
TreeNode buildTree(int[] inorder, int[] postorder);
```

类似, xem đặc điểm của duyệt hậu序và trung序:

```java
void traverse(TreeNode root) {
    traverse(root.left);
    traverse(root.right);
    // Duyệt hậu序
    postorder.add(root.val);
}

void traverse(TreeNode root) {
    traverse(root.left);
    // Duyệt trung序
    inorder.add(root.val);
    traverse(root.right);
}
```

Khác biệt thứ tự duyệt này, khiến phân bố phần tử trong mảng `postorder` và `inorder` có đặc điểm sau:

![](https://labuladong.online/algo/images/binary-tree-ii/5.jpeg)

区别mấu chốt của bài này và bài trước là, duyệt hậu序và duyệt tiền序ngược nhau, giá trị Node gốc tương ứng là phần tử cuối của `postorder`.

Khung thuật toán tổng thể rất类似bài trước, chúng ta vẫn viết một hàm phụ `build`:

```java
class Solution {
    // Lưu map từ giá trị tới index trong inorder
    HashMap<Integer, Integer> valToIndex = new HashMap<>();

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        for (int i = 0; i < inorder.length; i++) {
            valToIndex.put(inorder[i], i);
        }
        return build(inorder, 0, inorder.length - 1,
                    postorder, 0, postorder.length - 1);
    }

    // Định nghĩa của hàm build:
    // Mảng duyệt hậu序là postorder[postStart..postEnd],
    // Mảng duyệt trung序là inorder[inStart..inEnd],
    // Dựng cây nhị phân, trả về Node gốc của cây này
    TreeNode build(int[] inorder, int inStart, int inEnd,
                int[] postorder, int postStart, int postEnd) {
        // Giá trị Node root tương ứng chính là phần tử cuối của mảng duyệt hậu序
        int rootVal = postorder[postEnd];
        // Index của rootVal trong mảng duyệt trung序
        int index = valToIndex.get(rootVal);

        TreeNode root = new TreeNode(rootVal);
        // Đệ quy dựng cây con trái/phải
        root.left = build(inorder, ?, ?,
                        postorder, ?, ?);

        root.right = build(inorder, ?, ?,
                        postorder, ?, ?);
        return root;
    }
}
```

Giờ trạng thái tương ứng của `postoder` và `inorder` như sau:

![](https://labuladong.online/algo/images/binary-tree-ii/6.jpeg)

Chúng ta có thể按hình trên điền đúng index chỗ dấu hỏi:

```java
int leftSize = index - inStart;

root.left = build(inorder, inStart, index - 1,
                  postorder, postStart, postStart + leftSize - 1);

root.right = build(inorder, index + 1, inEnd,
                   postorder, postStart + leftSize, postEnd - 1);
```

Tổng hợp, có thể viết code解法đầy đủ:

```java
class Solution {
    // Lưu map từ giá trị tới index trong inorder
    HashMap<Integer, Integer> valToIndex = new HashMap<>();

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        for (int i = 0; i < inorder.length; i++) {
            valToIndex.put(inorder[i], i);
        }
        return build(inorder, 0, inorder.length - 1,
                    postorder, 0, postorder.length - 1);
    }

    // Định nghĩa của hàm build:
    // Mảng duyệt hậu序là postorder[postStart..postEnd],
    // Mảng duyệt trung序là inorder[inStart..inEnd],
    // Dựng cây nhị phân, trả về Node gốc của cây này
    TreeNode build(int[] inorder, int inStart, int inEnd,
                int[] postorder, int postStart, int postEnd) {

        if (inStart > inEnd) {
            return null;
        }
        // Giá trị Node root tương ứng chính là phần tử cuối của mảng duyệt hậu序
        int rootVal = postorder[postEnd];
        // Index của rootVal trong mảng duyệt trung序
        int index = valToIndex.get(rootVal);
        // Số Node của cây con trái
        int leftSize = index - inStart;
        TreeNode root = new TreeNode(rootVal);
        // Đệ quy dựng cây con trái/phải
        root.left = build(inorder, inStart, index - 1,
                            postorder, postStart, postStart + leftSize - 1);
        
        root.right = build(inorder, index + 1, inEnd,
                            postorder, postStart + leftSize, postEnd - 1);
        return root;
    }
}
```

## Dựng cây nhị phân qua kết quả duyệt hậu序và tiền序

Đây là bài 889 trên LeetCode「Dựng cây nhị phân theo duyệt tiền序và hậu序」, cho bạn nhập kết quả duyệt tiền序và hậu序 của cây nhị phân, bắt bạn还原cấu trúc cây nhị phân.

Chữ ký hàm như sau:

```java
TreeNode constructFromPrePost(int[] preorder, int[] postorder);
```

Bài này và hai bài trước có区别bản chất:

**Qua kết quả duyệt tiền序trung序, hoặc hậu序trung序 có thể xác định duy nhất một cây nhị phân gốc, nhưng qua kết quả duyệt tiền序hậu序 không cách nào xác định cây nhị phân gốc duy nhất**.

Đề cũng nói, nếu có nhiều kết quả还原khả thi, bạn có thể trả về bất kỳ loại nào.

Tại sao? Chúng ta nói,套路dựng cây nhị phân rất đơn giản, tìm Node gốc trước, rồi tìm và đệ quy dựng cây con trái/phải là được.

Hai bài trước, có thể qua kết quả duyệt tiền序hoặc hậu序 tìm Node gốc, rồi dựa vào kết quả duyệt trung序xác định cây con trái/phải (đề nói cây không có Node trùng `val`).

Bài này, bạn có thể xác định Node gốc, nhưng không cách nào确切biết cây con trái/phải có những Node nào.

Lấy ví dụ, ví dụ cho bạn nhập này:

```
preorder = [1,2,3], postorder = [3,2,1]
```

Hai cây dưới đều符合điều kiện, nhưng hiển nhiên cấu trúc chúng khác:

![](https://labuladong.online/algo/images/binary-tree-ii/7.png)

Nhưng nói lại, dùng kết quả duyệt hậu序và tiền序还原cây nhị phân, logic解法và hai bài trước差không nhiều, cũng là qua khống chế index của cây con trái/phải để dựng:

**1、Trước hết把phần tử đầu của kết quả duyệt tiền序hoặc phần tử cuối của kết quả duyệt hậu序xác định là giá trị Node gốc**.

**2、Rồi把phần tử thứ hai của kết quả duyệt tiền序làm giá trị của Node gốc cây con trái**.

**3、Tìm giá trị của Node gốc cây con trái trong kết quả duyệt hậu序, nhờ đó xác định biên index của cây con trái, rồi xác định biên index của cây con phải, đệ quy dựng cây con trái/phải là được**.

![](https://labuladong.online/algo/images/binary-tree-ii/8.jpeg)

Chi tiết xem code.

```java
class Solution {
    // Lưu map từ giá trị tới index trong postorder
    HashMap<Integer, Integer> valToIndex = new HashMap<>();

    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        for (int i = 0; i < postorder.length; i++) {
            valToIndex.put(postorder[i], i);
        }
        return build(preorder, 0, preorder.length - 1,
                    postorder, 0, postorder.length - 1);
    }

    // Định nghĩa: theo preorder[preStart..preEnd] và postorder[postStart..postEnd]
    // Dựng cây nhị phân, và trả về Node gốc.
    TreeNode build(int[] preorder, int preStart, int preEnd,
                   int[] postorder, int postStart, int postEnd) {
        if (preStart > preEnd) {
            return null;
        }
        if (preStart == preEnd) {
            return new TreeNode(preorder[preStart]);
        }

        // Giá trị Node root tương ứng chính là phần tử đầu của mảng duyệt tiền序
        int rootVal = preorder[preStart];
        // Giá trị của root.left là phần tử thứ hai của duyệt tiền序
        // Mấu chốt dựng cây nhị phân qua duyệt tiền序và hậu序 là qua Node gốc của cây con trái
        // Xác định区间phần tử của cây con trái/phải trong preorder và postorder
        int leftRootVal = preorder[preStart + 1];
        // Index của leftRootVal trong mảng duyệt hậu序
        int index = valToIndex.get(leftRootVal);
        // Số phần tử của cây con trái
        int leftSize = index - postStart + 1;

        // Dựng Node gốc hiện tại ra trước
        TreeNode root = new TreeNode(rootVal);
        // Đệ quy dựng cây con trái/phải
        // Dựa vào index của Node gốc cây con trái và số phần tử推biên index của cây con trái/phải
        root.left = build(preorder, preStart + 1, preStart + leftSize,
                postorder, postStart, index);
        root.right = build(preorder, preStart + leftSize + 1, preEnd,
                postorder, index + 1, postEnd - 1);

        return root;
    }
}
```

Chúng ta giả sử phần tử thứ hai của duyệt tiền序là Node gốc của cây con trái, nhưng thực tế cây con trái có thể là con trỏ rỗng, vậy phần tử này phải là Node gốc của cây con phải. Vì ở đây không cách nào确切判断, nên导致đáp án cuối không duy nhất.

Đến đây, vấn đề还原cây nhị phân qua kết quả duyệt tiền序và hậu序 cũng giải xong.

Cuối cùng呼应bài trước, **vấn đề dựng cây nhị phân thường đều dùng思路「phân rã bài toán」: dựng cả cây = Node gốc + dựng cây con trái + dựng cây con phải**. Tìm Node gốc ra trước, rồi dựa vào giá trị Node gốc tìm phần tử của cây con trái/phải, rồi đệ quy dựng cây con trái/phải.
